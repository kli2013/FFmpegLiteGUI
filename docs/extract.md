# 流提取页面功能总结

流提取页面（位于主界面的“流提取”标签页）用于从媒体文件中**无损提取**独立的视频、音频、字幕轨道，无需重新编码，保留原始质量。该页面支持批量处理、智能文件命名和元数据保留，是快速拆分多轨媒体文件的高效工具。

---

## 一、文件列表管理

- **添加文件**：通过按钮或拖拽（支持多选）添加一个或多个媒体文件到列表。
- **清空列表**：一键移除所有文件。
- **删除选中**：移除选中的文件（支持多选）。
- **预览选中**：在下方命令预览区显示选中文件的提取命令（不实际执行）。
- **发送选中**：将选中的文件按当前选项生成任务，添加到主界面的任务队列中。
- **双击行**：快速预览该文件的提取命令。

> 支持拖拽添加，且自动识别文件类型（仅媒体文件）。

---

## 二、提取选项（核心配置）

这些选项控制提取哪些流以及输出方式，实时影响命令预览和任务生成。

| 选项 | 说明 |
|------|------|
| **提取视频流** | 勾选后提取视频轨道，输出容器可选 `mkv`、`mp4`、`mov`。 |
| **提取音频流** | 勾选后提取音频轨道，输出格式可选 `m4a`、`mp3`、`flac`、`wav`、`aac`、`mka`。若启用“自动匹配”，则根据音频编码自动选择扩展名（如 AAC→`.m4a`、FLAC→`.flac`）。 |
| **提取字幕流** | 勾选后提取字幕轨道，输出格式可选 `srt`、`ass`、`vtt`、`mov_text`。若启用“自动匹配”，则根据字幕编码自动选择扩展名（如 ASS→`.ass`、SRT→`.srt`）。 |
| **仅提取第一轨** | 勾选后每种流类型只提取第一个轨道（如第一条音频、第一条字幕）；否则提取该类型的所有轨道。 |
| **按流类型分文件夹存放** | 勾选后，视频、音频、字幕分别存入 `video/`、`audio/`、`subtitle/` 子文件夹中。 |
| **保留章节** | 勾选后，提取时保留源文件的章节标记（`-map_chapters 0`）。 |
| **清除元数据** | 勾选后，输出文件不包含任何元数据（如作者、专辑、标题等），适用于素材或铃声提取。 |

> **提示**：音频自动匹配时，若编码为 AAC，扩展名会选 `.m4a`（而非 `.aac`），因为 M4A 容器支持章节和元数据保留更好。

---

## 三、输出目录控制

- **输出到自定义目录**：启用后可浏览选择输出目录，否则输出文件默认保存在输入文件所在目录。
- 自定义目录路径会被记忆（保存在用户设置中），下次打开自动恢复。

---

## 四、命令预览区

- 显示**当前选中文件**基于当前提取选项生成的所有 FFmpeg 命令（每个流一条命令）。
- 预览内容包含：
  - 输入文件路径。
  - 提取的流类型及索引。
  - 输出路径（自动根据选项生成文件名，若提取多个同类型流，文件名会加上流索引和语言代码）。
  - 元数据（语言、标题）的保留或清除。
- 方便用户核对提取规则，并可手动复制命令自行执行。

---

## 五、批量任务生成

- **发送所有到任务队列**：为文件列表中的**每一个文件**，根据当前提取选项生成所有对应的提取命令，并批量添加为自定义任务。
- 任务会显示在主页面的任务列表中，可直接启动队列进行批量提取。
- 每个任务独立，互不影响，支持并行处理。

---

## 六、文件名与元数据智能处理

- **自动添加语言代码**：如果流中含有语言信息（如 `language=chi`），文件名中会追加 `_chi`，便于识别。
- **保留标题**：提取时会将源流的 `title` 元数据写入输出文件（除非清除元数据）。
- **自动匹配扩展名**：根据编码类型自动选择最适合的容器/扩展名，避免因扩展名不兼容导致播放器无法识别。

---

## 七、典型使用场景

- **拆分多音轨/多字幕视频**：从一部电影中提取多条音轨（如不同语言）或字幕文件。
- **提取视频素材**：从录屏或拍摄素材中单独抽出视频流用于剪辑。
- **提取背景音乐**：从 MV 或视频中提取音频流，保存为独立音频文件。
- **备份字幕**：将内嵌字幕提取为外部字幕文件，便于编辑或用于其他视频。
- **批量提取**：将一个文件夹中的多个视频文件一次性全部拆分为视频、音频、字幕流。

---

流提取页面通过直观的选项和实时预览，让用户能够**无损、快速、批量**地从媒体文件中剥离所需轨道，是处理多轨视频文件的得力助手。配合任务队列，可轻松完成大规模素材预处理工作。
