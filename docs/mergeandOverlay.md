# 合并/封装/画中画页面功能总结

## 一、页面概述

合并页面（封装/合并/画中画）是 FFmpeg 多功能工具的核心模块之一，用于将多个视频、音频、字幕流组合成一个输出文件。它支持三种主要工作模式：

- **普通封装模式**：将主视频与外部音频/字幕合并，可重新编码或流复制。类mkvtoolnix
- **画中画模式**：将一个或多个子视频（或图片）叠加在主视频之上，支持位置、大小、透明度、绿幕抠像、循环播放等高级效果。
- **串行合并模式**：将多个视频按顺序首尾拼接，支持流复制（快速）或重新编码（兼容性强）。**在重新编码模式下，每个片段现支持完整的独立滤镜（裁剪、旋转、翻转、反交错、增强、截取、倒放、变速）**，同时自动强制统一规格以确保拼接成功。   
  (不要勾选画中画和串行合并就是普通封装模式)
---

## 二、主要功能区（通用）

### 1. 主视频与轨道管理

- **主视频文件**：选择作为基底的主视频文件。
- **轨道列表（Treeview）**：
  - 显示所有已添加的轨道（视频、音频、字幕），包括启用状态、类型、规格（分辨率/时长/编码等）、编码设置等。
  - 支持双击编辑单个轨道的详细参数。
  - 支持拖拽添加文件（自动识别类型）。
  - 工具栏操作：启用/禁用、编辑、预览、上移/下移、删除、清空、排序（按文件名或修改时间）、保存/加载项目。
  - 右键菜单：对选中轨道提供 滤镜 复制/粘贴/还原、截取·变速·倒放 复制/粘贴、启用禁用、编辑、预览（含快照/实时）、创建缩略图、上移/下移、克隆、**替换素材**、删除、恢复列宽 —— 完整清单见第八章第 4 节。

### 2. 添加外部轨道

- **添加外部音轨**：导入音频文件（mp3, aac, wav, flac, opus, ac3 等）。
- **添加外部字幕**：导入字幕文件（srt, ass, ssa, vtt, idx, sup 等）。
- **添加外部视频**：在画中画或串行模式下，添加视频作为子视频或串联片段。

### 3. 模式选择与参数控制

#### 普通封装模式
- 将主视频与外部音轨/字幕合并，支持流复制或重新编码。
- 主视频可应用完整滤镜（裁剪、缩放、旋转、增强等），**并支持字幕烧录**（勾选「烧录字幕」+ 字符编码，2026-08-28 恢复；copy 编码自动转重编码）。
- 音频轨道可独立设置编码、比特率、采样率、音量等。
- 普通模式有个单独的仅音频模式(开始合并按钮左边)，和转换页面的仅音频的不一样，这里的主要是为了简单的把几个音频混合一下，比如解说和主视频混合为一条。

#### 启用画中画 (PIP) 
- 所有视频流强制重新编码，输出时长默认由主视频控制。
- 每个子视频可独立设置位置、大小、透明度、绿幕抠像、循环播放等。
- 子视频支持所有独立滤镜（裁剪、旋转、翻转、反交错、增强、截取、倒放、变速等）。
- 其实就是转换页面水印的加强版，水印只能一个子画面，画中画可以n个，因为我最开始实现的就是这里的画中画功能，后来才想到批量打水印。
- 功能名字是画中画，但其实不只是用来给大画面里放小画面，也可以把几个画面平铺拼接，比如3个竖屏想分3列拼个大的之类的，详情可以看下面的**画中画模式下的主视频偏移页面**
- 提供智能平铺功能，自动排列多个子视频。

#### 串行合并（首尾拼接）

这是将多个视频按顺序拼接成一个长视频的模式。它分为两种子模式：

##### 流复制模式（Copy 模式）
- **触发条件**：主视频和音频的编码器均为 `copy`，且所有输入视频的编码参数（分辨率、帧率、像素格式、编码格式）**必须完全一致**。
- **实现方式**：使用 FFmpeg 的 `concat demuxer`（`-f concat -safe 0 -i filelist.txt`），直接在二进制级别拼接文件。
- **特点**：速度极快（几乎等于文件复制），不重新编码，因此**所有滤镜（包括主视频的）都不会生效**，只做简单的首尾连接。
- **限制**：要求所有视频参数严格一致，否则会导致花屏、音画不同步或播放异常。**子轨道自身的任何设置（滤镜、截取等）完全被忽略**。

##### 重新编码模式（非 Copy 模式）
- **触发条件**：主视频或音频的编码器不是 `copy`（例如设为 `libx264`）。
- **实现方式**：使用 `filter_complex` 中的 `concat` 滤镜，，**每个片段（包括主视频和子视频）现在支持完整的独立滤镜链**：
  - **视频**：裁剪、旋转、翻转、反交错、增强（降噪/锐化/色彩校正）、截取、倒放、变速。  下方有详细补充
  - **音频**：截取、倒放、变速、静音生成（自动填充）。
  - **所有片段末尾强制统一**：分辨率、像素格式、帧率、SAR（以主视频为准），确保 concat 不报错。
  - **全局阶段（拼接后）仅保留**：字幕烧录（主视频）、文字水印（drawtext，主视频）。串行模式**取消单个音频**的方法不是取消启用的勾，而是在相关视频的音频绑定里里选**生成静音流**。（2026-08-28 恢复：封装页烧录接口完全恢复，三种模式均支持烧录+charenc）

当主视频编码器设为非 `copy`（如 libx264）时，系统进入重新编码模式。此时每个视频轨道（包括主视频和所有子视频）均可双击编辑，并应用以下独立滤镜：

##### 支持的功能（视频）
- **裁剪 (crop)**：自定义区域。
- **旋转 (rotate)**：90°/180°/270°。
- **水平/垂直翻转 (hflip/vflip)**。
- **反交错 (deinterlace)**：yadif/bwdif 等。
- **增强 (enhance)**：降噪、锐化、色彩校正等（作用于该片段内部）。
- **截取 (trim)**：指定开始/结束时间，截取片段部分。
- **倒放 (reverse)**：该片段视频倒放。
- **变速 (speed)**：自定义播放速度（与音频同步）。

##### 支持的功能（音频）
- **截取 (trim)**：与视频截取同步，时长自动匹配。
- **倒放 (reverse)**：仅「外挂音轨」可在音频轨道设置里独立勾选；视频自带音轨不再跟随视频倒放（已全面解绑）。
- **变速 (speed)**：仅「外挂音轨」可独立设置（atempo 链）；视频自带音轨不再跟随视频变速。
- **静音生成 (silence)**：若片段无音频或用户选择，自动生成匹配时长的静音流。

##### ⚠️ 强制统一（自动覆盖）
每个片段处理完成后，系统会在滤镜链末尾强制添加：
- `scale={主视频目标宽}x{主视频目标高}`（统一分辨率）
- `format={主视频目标像素格式}`（统一像素格式）
- `fps={主视频目标帧率}`（统一帧率）
- `setsar=1`（统一采样纵横比）
- `setpts=PTS-STARTPTS`（重置时间戳）

这些强制操作确保所有片段在进入 `concat` 前规格完全一致，**不会产生拼接错误**。

##### 全局阶段（拼接后）
- **视频**：仅应用主视频的字幕烧录（若有，带 charenc）与文字水印（drawtext）。**字幕烧录 2026-08-28 恢复**：封装页烧录接口完全恢复，普通封装/画中画/串行三种模式全部支持。
- **音频**：**不再应用音量调整**（已移除），串行模式下不提供整体或独立音量控制。

##### 4. 章节与元数据处理

- **复制源文件章节**：自动保留主视频的章节标记（`-map_chapters 0`）。
- **导入外部章节文件**：支持 FFmetadata 格式的章节文件（`-i meta.txt -map_chapters N`）。
- **片段章节标签**（串行合并模式）：每个视频/音频轨道的元数据页提供「章节标签」输入框，可为每个片段指定章节名称。未填写时自动使用默认标签（如"片段 1"、"片段 2"…）。
- **生成章节**（串行合并模式）：勾选后，合并命令自动根据各片段的标签和时长生成 FFmetadata 临时文件并注入章节。预览模式跳过临时文件创建。

##### 5. 输出设置

- **输出容器**：MKV、MP4、WebM（根据模式自动推荐）。
- **输出文件路径**：自定义保存位置。
- **删除源文件**：合并成功后把源文件移动到回收站／垃圾箱（**非永久删除**），有二次确认；工具提示注明此为软删除。
- **验证输出文件**：合并后检查文件完整性。

##### 6. 命令预览与控制

- **实时命令预览**：显示即将执行的 FFmpeg 命令（可编辑、但不影响原始命令，只作为可复制的临时修改）。
- **刷新命令**：强制重新生成命令。
- **复制命令**：将命令复制到剪贴板。
- **开始合并**：执行合并操作，实时显示进度日志。

### 4. 末端处理（多画面拼接 / 末尾追加 / 边框，2026-08-25 首发 / 2026-08-27 边框）

封装页工具栏 **「末端处理」按钮**（转换页「高级选项」页与队列任务编辑里也有同一功能的按钮，三处设置互相独立）打开末端处理设置窗口。它在**整条滤镜链的最末端**对输出画面做处理，与上面「串行合并（首尾拼接）」**不是一回事**：串行合并是把多个**输入片段**按顺序拼接；末端处理是对**当前输出**再追加/分割/加框。三个功能块相互独立，可同时启用：

1. **多画面拼接（split 网格）**：把输出画面切分成 2~5 份拼成网格。
   - 行×列分别设置（1×3 横排、2×2 四宫格…），总格数限 2~5。
   - 实现=ffmpeg `split` + `hstack`/`vstack`（逐行横拼再竖拼）。
2. **末端 concat（图片/视频追加）**：在视频末尾追加一段图片（如二维码、片尾图，显示秒数可设）或视频文件。
   - 图片自动缩放适配输出尺寸、不足黑底居中；视频需提前准备好匹配的规格。
   - **会强制重编码**（滤镜必须）。
3. **边框（pad 画布外扩）**：在最终画布四周加边框，与 split/concat 可同时启用。
   - 上/下/左/右四边距独立（像素），颜色支持 `#RRGGBB` 或颜色名（black/white/red…）。
   - **边框位置**下拉：`split 之后（网格外框，默认）`= 整个网格外面一圈边框；`split 之前（每格带框）`= 每份画面先加框再拼网格（格间边框背靠背，视觉 2 倍边距线）。未启用多画面拼接时两种位置效果相同。
   - 实现=ffmpeg `pad` 滤镜（HandBrake Pad 同款）；输出尺寸奇数自动向上取偶（yuv420p 要求）；纯 copy 编码自动切换重编码。

**预览支持**：命令预览（文本区）实时体现；封装页实时预览（mpv lavfi）支持完整网格+边框（含 2×2 等多行网格）；转换页播放预览支持边框与单级网格（行=1 或列=1），多行网格提示走复杂预览/实时预览。

## 三、画中画模式下的主视频偏移页面（详细说明）

当启用画中画模式后，编辑主视频轨道时，会进入一个包含 **“叠加/偏移”** 标签页的设置窗口。该页面分为左右两栏：

- **左栏**：主视频的画布偏移设置（pad 滤镜）。
- **右栏**：针对所有子视频（非主视频）的批量操作工具和智能平铺功能。

### 左栏 – 主视频画布偏移

- **启用画布偏移**：勾选后，主视频将被放置在一个更大的黑色画布上。
- **画布宽度/高度**：手动设置画布尺寸。
- **偏移 X/Y**：主视频内容在画布内的偏移量（支持负数）。
- **获取尺寸**：自动从主视频文件读取分辨率并填入。
- **可视化编辑画布偏移**：打开图形化窗口，拖拽蓝色矩形调整主视频在画布中的位置，可直观调整偏移量。

### 右栏 – 子视频批量操作与智能平铺

此区域提供对 **所有子视频（即除主视频外的所有视频轨道）** 的快捷操作，极大提升多视频布局的效率。

#### 按钮详解

| 按钮 | 功能描述 |
|------|----------|
| **取消子视频缩放/裁剪** | 一键取消所有子视频的“启用缩放”和“启用裁剪”复选框，恢复子视频为原始尺寸。适用于希望以原始分辨率进行平铺或手动调整的场景。 |
| **统一高度** | 将所有视频轨道（包括主视频）的高度统一为指定的像素值，宽度按原比例自动缩放。此操作会启用每个视频的缩放并设为“高度优先”模式。 |
| **统一宽度** | 与“统一高度”类似，将所有视频轨道的宽度统一为指定值，高度按比例缩放。 |
| **修改子视频编码** | 将所有子视频的编码器统一设置为 libx264（H.264）。只用来消除“copy 被忽略”的日志提示，没有其他实际用途。 |
| **恢复为 copy** | 将所有子视频的编码器恢复为流复制（copy），适用于计划从画中画变更到串行合并模式或需要保留原始编码的情况。 |
| **计算平铺** | **核心功能**：根据所有视频（主视频+子视频）当前的 **实际渲染尺寸**（考虑已应用的缩放、裁剪、旋转等），自动计算最佳排列布局，并更新每个子视频的叠加位置以及主视频的画布大小。 |

#### “计算平铺”参数说明

- **每行/每列**：控制横向优先或纵向优先时的基本单位数量。
- **方向**：可选择“自动”、“横排优先”或“竖排优先”。
  - **自动**：根据视频总宽高比自动选择更接近 16:9 的方向。
  - **横排优先**：按行排列，适合宽屏显示器。
  - **竖排优先**：按列排列，适合竖屏或手机视频。

**工作原理**：
1. 获取主视频的当前渲染尺寸（从滤镜设置中实时计算）。
2. 获取每个子视频的当前渲染尺寸（同样考虑其自身的缩放/裁剪）。
3. 根据所选方向，将视频排列成网格，计算所需画布的总宽度和高度。
4. 自动更新主视频的画布尺寸（pad 滤镜）和每个子视频的 overlay 坐标，使视频整齐排列在画布中。
5. 所有更改实时反映在轨道列表和命令预览中。

> **提示**：若要获得最佳的平铺效果，建议先使用 **“取消子视频缩放/裁剪”** 恢复所有子视频的原始尺寸，或手动调整每个子视频的缩放/裁剪，然后再执行“计算平铺”，以免尺寸不一致导致布局错乱。

## 四、其他便捷功能

- **保存/加载项目**：将当前所有轨道、设置、布局保存为 `.fflgproject` 文件，便于后续继续编辑。本质是 JSON 文件，可用文本编辑器打开查看或修改。**与转换页的「导出/导入项目」互不通用**：封装页项目文件不带 `project_type` 键，转换页项目带 `project_type = "convert"`；互相打开时会提示去另一页操作，不会静默加载错数据。
- **排序功能**：按文件名或修改时间对轨道排序（仅在串行合并模式下可用）。
- **拖拽添加文件**：支持从文件管理器直接拖拽文件到轨道列表，自动识别类型并添加。
- **轨道编辑**：双击任意轨道可进入详细设置，支持视频滤镜、音频参数、字幕语言/标题等精细控制。在串行合并重新编码模式下，子视频的裁剪、缩放、旋转等独立滤镜现在生效，但变速/倒放/字幕由全局控制。

## 五、典型工作流程建议

### 场景 1：普通封装（单视频+外部音轨/字幕）
1. 选择主视频。
2. 添加外部音轨/字幕（普通模式）。
3. 调整主视频的滤镜（如有需要）。
4. 设置输出路径，点击“开始合并”。

### 场景 2：画中画（多视频叠加）
1. 启用画中画模式。
2. 添加主视频和子视频。
3. 双击每个子视频，设置裁剪/缩放/绿幕/循环等独立参数。
4. 如需批量布局，使用“取消子视频缩放/裁剪”恢复原始尺寸，再执行“计算平铺”。
5. 预览效果，调整位置（可手动输入坐标或使用可视化编辑器）。
6. 输出合并。

### 场景 3：串行合并（多片段拼接，统一规格）
1. 启用串行合并模式。
2. 添加所有片段（按顺序排列）。
3. 若需要每个片段独立裁剪/旋转/增强/截取/倒放/变速，双击片段进行设置。
4. 将主视频编码器设为非 `copy`（触发重新编码）。
5. 系统自动强制统一规格并拼接。
6. 设置输出，开始合并。

## 六、注意事项

- **流复制模式**下所有滤镜均被忽略，仅当所有输入参数完全一致时可用。
- **画中画模式**下子视频的独立滤镜全部生效，但不支持流复制（强制编码）。
- **串行重新编码模式**下，增强、变速、倒放等效果作用于片段内部，拼接处不会跳变。
- **音量控制**在串行模式中已移除，请确保输入音频电平大体一致，或使用预处理。
- **绿幕/循环控制**仅在画中画模式且子视频可见，串行模式中自动隐藏。

---

通过清晰的模式划分和强大的独立滤镜支持，合并页面能够满足从简单封装到多轨叠加、片段拼接等各类复杂需求，是 FFmpeg 多功能工具中功能最完善的模块之一。

## 七、音频轨与字幕轨高级设置

双击轨道列表中的任意音频轨或字幕轨，可打开详细设置对话框。除基础的编码、音量／语言／标题外，近期新增以下高级功能：

### 1. 音轨时间偏移对齐（延后秒数）
- 音频轨对话框内新增「时间偏移对齐（延后秒数）」帧。
- 填入正值 N，表示该音轨**延后 N 秒**出现（适用于配音比原声晚 N 秒的对齐），内部通过 `adelay` 滤镜在头部补静音实现。
- 填 0 或留空表示不偏移。注意：启用偏移会触发音频重新编码（copy 编码器自动转为 aac）。

### 2. 默认轨（disposition）
- 音频轨与字幕轨对话框均新增「默认轨」下拉，可选 `default` / `none` / `forced` / `hearing_impaired` / `visual_impaired`，留空则首轨默认为 default。
- 对应输出 `-disposition:a:N` / `-disposition:s:N`，用于双语字幕、强制字幕（播放器默认显示）、听力／视觉障碍字幕等场景。

### 3. 套用同源视频轨（V→A）
- 对象：拖入视频文件时选「添加音频」生成的**同源音频轨**（其 `file_path` 与源视频相同）。外部单独拖入的纯音频文件无对应视频轨。
- 对话框「套用同源视频轨截取、变速、倒放(v→a)」按钮：一步把对应视频轨的 截取／变速／倒放 套用到本音频轨（写入明确值，可自由取消）。
- 右键「批量同源音频套用视频 (V→A)」：仅对**选中轨道**中的同源音频轨批量套用，越界自动钳制并一次性汇总提示。
- 套用后实时刷新轨道列表与命令预览。

### 4. 音频独立截取（不分段，仅串行合并模式）
- 分段拼接（SegmentEditor）窗口中，分段列表与「分段切割」之间新增「音频独立截取（不分段）」帧。
- 启用后输入起止时间，音频按指定区间裁剪，而视频仍按各分段拼接——常用于音乐只剪头尾来匹配总长度、中间不断。
- 勾选后才可编辑；窗口实时显示「分段视频总时长」参考（含逐段变速）。

### 5. 音量调整
- 音频轨对话框提供「启用音量调整」开关 + 音量滑块，与编码、比特率、采样率独立控制。

## 八、片段淡入淡出与串行转场（xfade）

### 1. 视频轨「淡入淡出」页
- 双击视频轨（串行合并重新编码模式）打开设置，「淡入淡出」页可勾选「启用淡入淡出」并设淡入／淡出时长（秒，同一行）。
- 通过 `fade=t=in` / `fade=t=out` 实现片段首尾渐黑；未知时长时跳过淡出、淡入仍生效。

### 2. 串行转场（xfade，逐轨常驻属性）
- 转场是**每条视频轨的常驻属性**（挂本段：本段控制「本段 → 下一段」之间的过渡），不再是合并页的全局开关。
- 串行合并模式下，每条视频轨的「淡入淡出」页都有「启用串行转场」复选框 + 「转场类型」下拉 + 「转场时长(秒)」输入框。
- **末段无下一段，其转场行灰显**（勾选／下拉禁用），转场开关自动无效。
- 转场类型（ffmpeg `xfade` 的 `transition`）逐轨独立可选：fade / fadeblack / fadewhite / fadegrays（淡入淡出类）、wipeleft / wiperight / wipeup / wipedown（擦除）、slideleft / slideright / slideup / slidedown（滑动）、smoothleft / smoothright / smoothup / smoothdown（平滑滑动）、circlecrop / circleclose / circleopen / zoomin（形状缩放）、dissolve / pixelize / radial（其它）。
- 转场时长自动钳制为「相邻两段中较短者的一半」，避免过短片段出错。
- **与淡入淡出互斥（逐轨判断）**：本段开了转场 → 本段的淡出被转场替代；上一段开了转场 → 本段的淡入被替代；**首段淡入 / 末段淡出仍保留**为整段输出的起止淡黑。未开转场的相邻片段之间仍为硬切，互不影响。
- **音频自动跟随**：音频段与视频段一一对应，跟随对应视频段的转场开关做 `acrossfade` 交叉淡入淡出（时长与视频转场一致），无需单独设置音频转场。

### 3. 「一键淡入淡出(all)」与「一键转场(all)」按钮（主视频「淡入淡出」页）
- 在**主视频**的「淡入淡出」页、串行合并模式下，底部一行并排放两个批量按钮，各自带独立的「时长(秒):」框（默认 1.0s，可自由填写）：
  - **一键淡入淡出(all)**：为所有启用的视频／音频轨写入淡入淡出设置（片段较短时自动钳制为 `min(1.0, dur*0.4)`）。
  - **一键转场(all)**：为所有启用的视频轨（除末段）开启串行转场；类型取当前下拉框，时长取本行框，末段自动跳过。
- 两个时长框**完全解耦**，互不影响。
- 点击后会同步刷新当前正在编辑窗口的对应勾选框／下拉／时长框，因此「保存」时不会把刚设好的设置覆盖掉。

### 4. 右键菜单相关操作一览

> 在轨道列表任意一行**右键**调出；以下为完整清单（按功能归组）。多数操作作用于「选中轨道」（支持多选）。

**① 滤镜设置：复制／粘贴／还原**
- 「复制滤镜设置」：从选中的第一个轨道复制滤镜参数（采用「默认全复制 + 显式排除」策略，仅跳过不能跨轨复制的项）。
- 「粘贴滤镜设置」：把剪贴板里的滤镜设置套用到选中轨道（剪贴板为空时该项灰显不可点）。
- 「还原滤镜设置」：把选中轨道的滤镜设置重置为默认（清空所有滤镜）。

**② 截取／变速／倒放（V→A）**
- 「复制 截取/变速/倒放 (V→A)」：复制选中视频轨的 截取／变速／倒放 设置（仅选中含视频轨时可用）。
- 「粘贴 截取/变速/倒放 (V→A)」：将上述设置套用到选中的音频轨（仅存在剪贴板时可用；含时长越界安全保护）。
- 「同源音频批量套用同源视频 T S R (V → A)」：对选中轨道中的**同源音频轨**，批量套用其对应视频轨的 截取/变速/倒放，越界自动钳制并一次性汇总提示（详见第七节省 3）。

**③ 播放、预览与缩略图**
- 「启用/禁用」：切换选中轨道的启用状态。
- 「编辑轨道」：打开选中轨道的详细设置对话框（等同双击该行）。
- 「预览轨道」：预览选中轨道的画面。
- 「预览轨道（快照 - 画中画合成）」：生成一张「画中画合成后」的快照预览。
- 「实时预览（复杂滤镜）」：用 mpv／ffplay 外部窗口实时合成预览，**按当前模式自动选图**——画中画模式＝主视频叠加各子视频；串行合并模式＝多段拼接＋转场＋逐轨滤镜（含文字水印）。串行合并模式下需 mpv 或 ffplay 可用，否则该项置灰；单轨模式请改用「预览轨道」。
- 「实时预览（简易时间引擎，画面小）」：同一张合成图改走内置时间预览窗口（ffmpeg 管道，不依赖 mpv，帧率不高），保留标记／波形／逐帧步进／循环。
- 「串行合并预览 (无滤镜 mpv EDL)」（仅串行合并模式，需 mpv）：**任何滤镜都不开**，只把各视频轨按列表顺序首尾连接起来播一遍——可以理解成一个**带截取属性的播放列表**：每段的截取（起止点）照旧生效，滤镜／转场／文字水印一律不参与。适合「只想确认前后接得对不对」的场合。文件名含 `=` 的段会被跳过并在日志点名（内联 `edl://` 的 URL 解析限制）。
- 「串行合并导出 EDL 文件」（仅串行合并模式）：把上面这份播放列表落盘成 mpv 原生 `.edl` 文件（LF 换行，可直接拖进 mpv 播放核对）。与内联预览的区别：允许路径含 `=`，且可长期保存／分享／二次编辑；导出本身不依赖 mpv。
- 「创建缩略图」：对选中的第一个视频轨生成缩略图 contact sheet（主视频会按当前模式模拟叠加／拼接后的画面）。
- 「多流同步参考」：打开多轨波形对齐窗口，导出各轨的 `-ss/-to` 截取时间，也可一键**写回各轨的截取设置**（详见第十六章）。

**④ 轨道顺序与结构**
- 「上移轨道」/「下移轨道」：调整选中轨道在列表中的顺序。
- 「克隆轨道」：深拷贝选中轨道（含全部滤镜／截取／叠加／转场设置）插入原轨道之后；多选时克隆第一个。
- 「替换素材」：**只换源文件**，布局与滤镜整块保留（详见下方专述）。
- 「删除轨道」：删除选中轨道。
- 「恢复列宽」：把轨道列表各列恢复为默认宽度。

**⑤ 替换素材（2026-09-11 新增）**
- **核心语义：只换源文件。** 选中轨道 → 右键「替换素材」→ 选新文件；仅更新该轨道的源文件路径，**位置／缩放／旋转／裁剪／滤镜／截取／转场等编码设置整块保留，不做任何自动适配**（刻意不做「剪映式换源自动重排」）。
- **主视频轨双写同步**：若替换的是主视频轨，会同时更新主视频变量，避免「自己叠自己」或源路径失配。
- **只提示、不改参**：换源后按新素材校验，全部以**日志行**提示（不弹窗、不动任何参数）：
  - 新源没有对应类型的流（视频轨无 video 流／音频轨无 audio 流）；
  - 视频轨音源=自身，但新源无音频流（命令可能失败）；
  - 本轨已启用绿幕抠像（抠像颜色／相似度需按新素材重调）；
  - 新源时长与旧源不同（转场／淡入淡出／轨迹等**绝对秒参数不自动适配**）；
  - 截取结束时间超出新源时长（输出会被静默截断）。
- 新文件不存在、或与当前源相同 → 仅记一行日志，不做任何改动。
- 布局为何能保留：子视频位置默认用相对表达式、裁剪尺寸默认相对原尺寸计算，换源后自适应新尺寸。

> 注：「一键淡入淡出(all) / 一键转场(all)」已不是右键菜单项，而是主视频「淡入淡出」页内的按钮（见本节第 3 点）。

### 5. 附录：24 种转场类型详解（xfade transition）

> 转场类型下拉框共 24 种，分 6 大类。以下按类说明每种转场的画面表现，便于按需选择。

#### 1. 淡入淡出类 (Fade)
这类转场主要通过控制画面的透明度或颜色来实现平滑过渡。

- **fade**：最基础的交叉淡入淡出。前一个画面逐渐变透明，后一个画面逐渐显现，两者在过渡期间会有重叠融合的效果。
- **fadeblack**：向黑场过渡。前一个画面逐渐变暗直至全黑，然后后一个画面从全黑中逐渐亮起。
- **fadewhite**：向白场过渡。前一个画面逐渐变亮直至全白，然后后一个画面从全白中逐渐显现。
- **fadegrays**：向灰场过渡。与上述类似，但前一个画面是逐渐过渡到灰色，然后后一个画面再从灰色中显现。

#### 2. 擦除类 (Wipe)
这类转场模拟了物理遮挡物扫过屏幕的效果，前一个画面被直接"推走"或"擦掉"，露出后一个画面。

- **wipeleft**：从右向左擦除。前一个画面从右侧向左侧退出，后一个画面随之出现。
- **wiperight**：从左向右擦除。前一个画面从左侧向右侧退出。
- **wipeup**：从下向上擦除。前一个画面从底部向顶部退出。
- **wipedown**：从上向下擦除。前一个画面从顶部向底部退出。

#### 3. 滑动类 (Slide)
与擦除类似，但滑动类转场会保留画面的整体感，就像两张卡片在屏幕上滑动替换。

- **slideleft**：向左滑动。前一个画面整体向左滑出屏幕，后一个画面从右侧滑入。
- **slideright**：向右滑动。前一个画面整体向右滑出，后一个画面从左侧滑入。
- **slideup**：向上滑动。前一个画面向上滑出，后一个画面从底部滑入。
- **slidedown**：向下滑动。前一个画面向下滑出，后一个画面从顶部滑入。

#### 4. 平滑滑动 (Smooth)
在普通滑动的基础上增加了缓动（Ease-in/Ease-out）动画曲线，使得滑动在开始和结束时会有加速和减速的过程，视觉上更加自然、流畅。

- **smoothleft / smoothright / smoothup / smoothdown**：分别对应向左、右、上、下的平滑滑动，动作表现与滑动类相同，但节奏感更好。

#### 5. 形状与缩放 (Shape & Zoom)
这类转场利用几何图形或画面缩放来切换内容。

- **circlecrop**：圆形裁剪过渡。通常表现为一个圆形区域逐渐扩大或缩小，以此来显示或隐藏画面。
- **circleclose**：圆形闭合。一个圆形从屏幕四周向中心收缩，闭合后切换为后一个画面（或后一个画面从中心圆形展开）。
- **circleopen**：圆形展开。与 circleclose 相反，一个圆形从屏幕中心向四周扩大，逐渐展示后一个画面。
- **zoomin**：缩放过渡。前一个画面快速放大（Zoom In）直至充满屏幕，然后切换为后一个画面。

#### 6. 其他特效 (Others)
- **dissolve**：溶解。前一个画面的像素像沙化或噪点一样逐渐消散，同时后一个画面逐渐浮现，带有一种梦幻或老电影的质感。
- **pixelize**：像素化。前一个画面逐渐变成马赛克（像素块），直到完全变成色块后，再逐渐清晰还原为后一个画面。
- **radial**：径向过渡。以屏幕中心为原点，呈放射状（像雷达扫描或扇形展开）逐渐切换出后一个画面。

## 九、遮罩 / 透明蒙版

遮罩是一个独立功能（不是给某个滤镜加开关），作用在封装页的「子视频 / 文字水印」上，用于把子视频的一部分做成透明、让主视频（或画布）透过显示。入口在视频轨编辑器的「循环/绿幕控制」页、「透明度」复选框右侧的「遮罩」按钮（与透明度间隔 `padx=25`）。

同一「循环/绿幕控制」页还提供每子视频独立的 **「音频:」模式下拉**（默认 / 忽略 / 混音 / 替换），控制子视频音频的处理方式，详见第十七章。

### 1. 打开遮罩对话框
- 点击「遮罩」弹出设置框。**2026-09-11 起改为「上列表 + 下参数」的单弹窗**（可放多个形状，详见第十五章）：顶部「启用遮罩」总开关 → 形状列表（启用 / 类型 / 方向 / 坐标摘要，点「启用」列切换单项）→ 编辑选中形状（方向单选 / X·Y·宽·高 + 🎯 可视化选区 / 边缘羽化 / 外部形状图 / 时段 / 轨迹）→ 保存 / 取消。
- 坐标空间 = 子视频**最终渲染帧**（crop→rotate→scale 之后），与弹窗画布同构、零换算；不再有「📋 从裁剪复制坐标」按钮（改为列表内独立选区）。
- ⚠️ 总开关「启用遮罩」必须勾选并点「保存」，遮罩段才会写进转换命令；形状列表为空时保存会自动关闭总开关（避免 0 尺寸矩形把整个画面刷黑）。

### 2. 遮罩方向
- **遮罩区域外（只露矩形）**：黑底白矩形 —— 矩形内不透明、矩形外透明，主视频从矩形外透出。
- **遮罩区域内（矩形透明）**：白底黑矩形 —— 矩形透明、矩形外正常，主视频从矩形孔洞透出。

### 3. 适用范围与实现
- 遮罩对「画中画子视频」与「文字水印」均生效（两者共用同一「循环/绿幕控制」编辑器）。
- 底层用 `alphamerge`：把灰度蒙版写入 alpha 通道（白=不透、黑=透明）。本机 ffmpeg 不带 `mask` 滤镜，故走 `format=rgba,split=2[a][m];[m]format=gray,drawbox…[msk];[a][msk]alphamerge`。`format=rgba` 在 split 之前锁死主输入像素格式——否则 matte 的 `format=gray` 会让 ffmpeg 自动格式协商把 scale 输出降级为 gray，整帧发灰（2026-09-10 修复）。
- 遮罩启用时，子视频管线强制 `format=rgba` 以保留 alpha；透明区在叠加时被主视频/画布透出，**无需 mov 等 alpha 封装**（合成时透明被主视频消费）。

### 4. 注意
- 遮罩属于封装页逐轨功能；转换页（单文件转码）不包含此设置，也不会出现在转换页任务队列中。

## 十、子视频放开边界（自由布局）

子视频叠加页（画中画）的「混合模式」下拉框右侧新增「放开边界」复选框，用于解除对子视频位置/大小的钳制。

### 1. 行为
- 勾选后：允许子视频比主视频大、可整体拖出主画面之外（可视化编辑器不滚动，超出部分自然出框）。
- 位置/大小原样送入 ffmpeg（`overlay` 本身支持负数/超出/比主视频大，超出部分由主帧裁掉）。
- 最终输出画布 = 主视频；主视频启用偏移/pad 时，底 = pad 画布。

### 2. 适用范围
- 对「子视频叠加」与「文字水印可视化编辑器」均生效；勾选状态随逐轨设置保存（`overlay_free_layout`）。

## 附：四种工作模式下滤镜「独立 / 联动」关系总览（含转换页）

本工具共有四类工作模式：① 转换页（单文件转码）② 封装模式（mux）③ 画中画模式（PiP）④ 串行合并模式（concat）。下面逐项说明**视频滤镜、音频创意滤镜、音频倒放、以及故意全局的滤镜**在各模式下的独立 / 联动关系。

### 总览表

| 滤镜类别 | 转换页 | 封装(mux) | 画中画(PiP) | 串行合并(concat) |
|----------|--------|-----------|-------------|------------------|
| 视频滤镜（裁剪/缩放/旋转/增强/反交错/变速/倒放…） | 单视频，自身设置 | 主视频自身设置 ✅独立 | 主+各子各自设置 ✅独立 | 各片段各自设置 ✅独立（+强制归一） |
| 音频创意滤镜（音量/EQ/淡入淡出/降噪/响度/声道/变速） | 自身设置 ✅独立 | 每条音轨各自设置 ✅独立 | 每条音轨各自设置 ✅独立 | 每条音轨各自设置 ✅独立 |
| 音频倒放 | 独立勾选 ✅（不跟随视频） | ✅ 纯独立（不再回退主视频） | ✅ 纯独立 | ✅ 纯独立（外挂音轨独立；视频自带音轨仅截取/重置，不再跟随视频倒放/变速） |
| 字幕烧录 `subtitles` | 单视频（无多轨联动问题） | 全局（主视频，合成到最终画面） | 仅主视频（全局） | 仅主视频（全局） |
| 文字水印 `drawtext` | 单视频 | 全局 | 全局（主视频） | 全局（主视频） |
| 强制规格归一（scale/format/fps/sar） | 无 | 无 | 无 | ✅ 故意全局（拼接必需） |

### ① 转换页（单文件转码）—— 全独立

- 只有一路视频、一路（或零路）音频。
- 视频倒放、音频倒放、音频变速、音量、EQ、淡入淡出等，**每一项都是独立的勾选框 / 滑块**，互不联动。
- 音频倒放（「音频倒放（独立于视频）」）默认不勾，勾了才倒放；视频倒放只影响画面。想音画一起倒放就两个都勾。
- 无「联动 / 分离」总开关（按设计保持全独立，最简单）。
- 故意全局项：字幕烧录、文字水印都只作用于这唯一的视频，不存在多轨联动问题；预览时倒放被禁用（播放器限制）。

### ② 封装模式（mux）

- 视频：主视频用自身设置，滤镜独立。
- 音频：每条外挂音轨的编码、音量、EQ、变速、淡入淡出、倒放等均**逐轨独立**。每条音轨的「音频倒放（独立于视频，仅当前轨道）」只控制自己，与主视频倒放完全无关。
- 故意全局项：字幕烧录（`subtitles=`，主视频烧录进最终画面）、文字水印（`drawtext`）。提示也写明「子视频可单独应用所有滤镜除了字幕」。（2026-08-28 恢复：普通封装模式同样支持主视频烧录+charenc）

### ③ 画中画模式（PiP）

- 视频：主视频与各子视频**各自独立的滤镜链**（裁剪/缩放/旋转/增强/反交错/截取/倒放/变速），互不干扰。
- 音频：每条音轨**完全独立**，音频倒放为纯独立（不跟随任何视频）。
- 故意全局项：仅主视频的字幕烧录、文字水印被合成到最终画面（子视频无法单独烧录字幕，这是合成层的限制，不是遗漏）。

### ④ 串行合并模式（concat）

- 视频：每个片段（主视频 + 各子片段）**各自独立的滤镜链**。在每个片段滤镜链末尾，**强制追加** scale/format/fps/setsar 归一（以主视频为准），这是拼接兼容性必需的**故意全局**动作，任何片段都无法豁免。
- 音频：
  - **外挂音轨**：逐轨独立，音频倒放 / 变速纯独立（在音频轨道设置里单独勾选）。
  - **视频自带音轨**：**完全独立**——仅做截取与基准 PTS 重置，**不再跟随该片段视频的倒放或变速**。若某片段视频做了倒放/变速而你希望嵌入音频也同步，请在单独在音频轨道设置里自己勾选倒放/变速；否则视频自带音轨将按原速正向播放。
  - **段级音频时长钳制（防累计错位）**：concat 是顺序拼接，每段音频占用区间 = 其处理后时长。当某段音频加了「时间偏移对齐」（adelay，段头补 N 秒静音拉长该段）、变速或截取后，若无收尾处理，每段边界处音画累计差会随段数增加而越来越大（段越多越歪）。为此，在每条音频段滤镜链**末尾**追加 `atrim=0:T_i,apad=whole_dur=T_i`（`T_i` = 对应视频段的处理后时长）：超长的切掉尾巴、不足用静音补到正好 `T_i`，使**每段音频总时长恒等于对应视频段时长**，彻底消除累计错位。独立音轨路径与（无独立音轨时回退的）嵌入音轨路径都做此对齐；嵌入音轨同时跟随其视频段的变速 / 倒放，使其自然时长就等于视频段时长，避免被静默截断。
    - **音频转场（acrossfade）**：音频段与视频段一一对应，跟随对应视频段的转场开关做 `acrossfade` 交叉溶解（时长与视频转场一致），转场区域音画同步、无接缝；未开转场的相邻音频段仍为硬切。音频总时长 = Σ 视频段时长 − Σ 各转场时长，与视频完全对齐。
  - **全局背景音乐 (BGM)**：仅**主视频（第一段）**的「音频绑定」页提供「叠加背景音乐」开关 + 音频文件选择 + 音量滑块（默认 0.3）。启用后，外部音频会**循环铺满整段合并输出**，按设定音量降低后通过 `amix`（normalize=0，不压低原音）**混在原有音频之下**。串行模式不再使用「独立外部音轨」的 1:1 段映射——该功能绑定语义未实现，且音轨数量与段数不匹配会导致部分段丢音，现已由本全局 BGM 取代。
- 故意全局项：字幕烧录（仅主视频）、文字水印（仅主视频）、以及上面提到的强制规格归一。

### 小结

- 视频滤镜与音频创意滤镜：四种模式**均已实现逐轨独立**。
- 音频倒放 / 变速：四种模式**现已全部完全独立**，不再有任何「音频跟随视频」的回退逻辑。具体为：封装模式移除「音轨倒放回退主视频」；串行模式移除「视频自带音轨回退该片段视频倒放/变速」。每条音频轨道（外挂或视频自带）的倒放/变速只由其自身设置在音频轨道设置里决定。
- 唯一的「跟随」关系只剩下**故意全局**项：字幕烧录、文字水印、以及串行模式的强制规格归一（scale/format/fps/sar）。这些本就该全局，不属联动问题。封装页三模式（普通封装/画中画/串行）的字幕烧录均支持 charenc（2026-08-28 恢复补全）。

## 十一、轨迹控制（动态水印）

水印/画中画除了静态定位，还支持**位置随时间循环移动**的动态轨迹。入口：子视频设置窗口「持续旋转」行右侧的 **「轨迹控制...」** 按钮（转换页图片水印设置同款组件）。

### 1. 四种预设轨迹

| 预设 | 行为 | 参数 |
|---|---|---|
| 左右往返 | 水印从画面最左到最右**整个宽度**来回横穿；y 用你设置的位置坐标控制距上边距 | 周期（管速度） |
| 上下往返 | 整个高度来回纵穿；x 用你设置的坐标控制距左边距 | 周期 |
| 歪菱形循环 | 按轨迹编辑器 5×5 网格的 4 个点位 `(4,1)→(1,2)→(2,5)→(5,4)` 走斜菱形轨迹，**等速**（各段用时与边长成正比） | 周期 |
| 四角跳跃 | 依次跳到屏幕四角（内缩边距），每点停留后瞬移下一角 | 每点停留 + 边距 |

### 2. 参数说明

- **周期（秒）**：管的是**速度**——周期越短，水印移动越快。往返 = 单程来回一次的时间；菱形 = 走完一圈的时间。四角跳跃不受此周期影响（用「每点停留」）。
- **每点停留（秒）**：四角跳跃时在每个角停留的时间。
- **边距**：四角跳跃时水印离屏幕边缘的距离，可填像素数（如 `20`）或相对式（如 `W*0.03` = 主画面宽度 3%）。

### 3. 与其他功能的关系

- **与循环控制（显示时段/循环显示/循环次数）互不干扰**：轨迹控制管「位置」（overlay 的 `x/y` 表达式），循环控制管「何时显示」（`enable` 表达式），两者是**正交维度**，可自由叠加。例如：四角跳跃 + 显示时段 5~10s = 只在第 5~10 秒跳角。
- **混合模式（blend）不支持动态轨迹**：使用叠加混合/滤色等混合模式时，轨迹设置会被忽略（退回基准位置），程序会提示。
- **与持续旋转可叠加**：转圈 + 移动互不影响。
- **实现原理**：x/y 使用含 `t` 的 ffmpeg eval 表达式（三角波/分段线性插值/st-ld 变量槽），无需外挂轨迹编辑器；生成命令时自动替换 overlay 的 x/y，基准坐标 `overlay_x/overlay_y` 保留不变，随时可改回静态。

### 4. 列表轨迹（waypoints 时间轨迹表，2026-08-27 内嵌版）

除四种预设外，轨迹控制弹窗还有 **「启用列表轨迹」勾选框**（勾选后上方预设下拉自动忽略，列表轨迹优先）。勾选后内嵌面板启用，**每一行 = 视频时间轴上的一个时间段**，行与行按时间顺序衔接，精确到秒级控制水印行为：

- **时间段**：每行的开始时间 + 持续（或开始/结束），终点行只能作为最后一行（静态定位，无时间段）。
- **平移**：行内可设起点坐标 → 终点坐标（画布绝对像素），该时间段内水印从起点线性移到终点；行尾位置自动作为下一行起点（连续平滑）。
- **隐藏**：勾选后该时间段水印完全隐藏（overlay 不渲染，非黑场/定格）。
- **自旋转**：边移边转（覆盖全局自旋转），可单独设置该段的旋转速度。
- **到期行为**：段末定格（位置停、子视频/自旋转不停）等。
- 行坐标可用「起点/终点」按钮打开可视化编辑器拖拽设定；面板显示总时长，红色竖线标记终点行。
- 上限 15 行（低于 ffmpeg 长表达式崩溃阈值 95~100 段），超出提示。

**实现**：`build_waypoint_expr` 把整张表编译成 overlay x/y 的 eval 表达式（含 `t` 每帧求值、`lt/mod` 分段、`st/ld` 变量槽），无临时文件；blend 模式同样支持（动态 crop 窗口跟随）。**与循环控制（显示时段/循环显示）正交**：轨迹表管"何时在哪/隐藏"，循环控制管"何时显示"，可叠加。

## 十二、轨道级新增参数（2026-09-07 ~ 2026-09-10）

封装页的视频轨编辑器（双击主视频 / 子视频 →「滤镜」页）与转换页**共用同一套滤镜面板**，所以下面这些新参数逐轨可用——主视频与各子视频各自一份、互不干扰；输出颜色标记与 GOP 在主视频与子视频的输出参数组装路径都会注入。

### 1. GOP 关键帧间隔（2026-09-09）
- 位置：滤镜页「帧率」同一行右侧 `GOP:` 输入框 + 「帧」，对应 ffmpeg `-g`。
- 留空 = 编码器默认（x264/x265 约 250 帧）；需要随机定位时填「帧率 × 目标秒数」（30fps 想 1~2 秒一个关键帧 → 30~60）。
- 值越小定位越准、体积越大；只影响重新编码，`copy` 不生效。

### 2. 输出颜色标记（2026-09-09）
- 位置：「高级增强」窗口右栏「输出颜色标记」：**原色 / 传输 / 矩阵 / 范围** 四个下拉，写的是输出文件的颜色**元数据**（`-color_primaries` / `-color_trc` / `-colorspace` / `-color_range`）。
- **随源 = 不干预**（沿用源标记；源没标或标错，输出同样缺失）。重编码后不重打标记，是 HDR 片段在部分播放器发灰 / 偏色的常见原因。
- 只写标记，不做任何像素转换（像素转换用「色彩空间转换」滤镜）。
- 实测坑：libx264 / libx265 / libsvtav1 会**静默丢弃** `-color_primaries` / `-color_trc`，故这三个编码器改走私有参数（`-x264-params colorprim=:transfer=` / `-x265-params` / `-svtav1-params color-primaries=:transfer-characteristics=`）可靠落盘；矩阵 / 范围走通用选项即可。

### 3. HDR→SDR 色调映射（2026-09-09）
- 位置：「高级增强」窗口右栏「HDR→SDR 色调映射」：启用勾选 + 算法下拉 `hable`（通用推荐）/ `mobius`（保亮部细节）/ `reinhard`（对比柔和）。
- 滤镜链：`zscale=t=linear:npl=100,format=gbrpf32le,zscale=p=bt709,tonemap=<算法>:desat=0,zscale=tin=linear:t=bt709:m=bt709:p=bt709:r=tv,format=<像素格式>`。
- **要求源带 HDR10(PQ) / HLG 标记**；未标记的 HDR 源本构建无法强转（zimg "no path between colorspaces"）。已标记为 SDR 的源过链无副作用。
- 开启后点「保存并关闭」，仍为「随源」的颜色标记会自动补成 bt709 原色 / bt709 传输 / bt709 矩阵 / tv 范围；手动改过的值不动。

### 4. 区域效果一族（2026-09-07：delogo 家族注册表 + bleed 外扩）
视频轨「去水印/模糊」窗口的类型下拉，除 `delogo` / `boxblur` / `gblur` 外新增一整族**区域效果**，由注册表 `_REGION_EFFECT_FILTERS` 驱动（加类型只改注册表与 UI 常量，生成逻辑不动）：

| 类型 | 作用 | 强度参数 | 类别 |
|------|------|----------|------|
| `negate` | 局部反色 | 无 | 点运算 |
| `hflip` / `vflip` | 局部水平 / 垂直镜像（盖水印常比 delogo 插值自然） | 无 | 点运算 |
| `swapuv` | 局部交换 U/V（色差故障风） | 无 | 点运算 |
| `desat` | 局部去色 `hue=s=0` | 无 | 点运算 |
| `eq_bright` | 局部明暗 `eq=brightness=` | 亮度（默认 −0.3） | 点运算 |
| `black` / `white` | 局部纯黑 / 纯白遮盖 `lutyuv=` | 无 | 点运算 |
| `unsharp` | 局部锐化 | 强度（默认 1.5） | 邻域（卷积） |
| `avgblur` | 局部均值模糊 | 半径（默认 5） | 邻域（卷积） |
| `median` | 局部中值（去小斑点、小 logo） | 半径（默认 3） | 邻域（卷积） |

- **局部 / 全帧一个开关**：勾「仅应用到选定区域」= 只作用于坐标框（`delogo` 恒局部，开关灰显）；不勾 = 全帧 + 显示时段 = 时间段效果。与「显示时段 / 循环显示」正交，可叠加。
- **bleed 外扩**：卷积类在 crop 子图上跑时边界取不到真实邻域，与整帧结果差 11.2 dB（肉眼可见方块边）；先外扩 k px（blur 24 / unsharp·median 8）处理完再裁回，降到 64.9 dB。贴边 / 满幅用 `max(x−k,0)` / `min(…, iw−bx)` 表达式让 ffmpeg 自己钳制，既不会错位也不会因 crop 越界失败。点运算无接缝，不外扩。
- 无参滤镜挂 `enable` 必须用等号（`hflip=enable='…'`），带参才可用冒号——程序自动判断。

### 5. 与转换页的分工
入队预检 / 转后校验 / 大小预估、以及转换页的「导出 / 导入项目」**只存在于转换页队列**（封装页没有任务队列）；上面 1~4 项则是两页共用的同一套面板。

## 十三、遮罩轨迹与边缘羽化（2026-09-10）

「遮罩 / 透明蒙版」窗口（见第九章）新增两块：**边缘羽化**与**遮罩轨迹**。二者让原本静止的矩形变成一块沿轨迹移动的「揭示挡板」。

### 1. 统一心智模型：矩形 = 压在子视频上的挡板

遮罩矩形不再只是固定的透明区，而是**一块会移动的挡板**。尺寸 × 方向决定它是什么效果：

| 矩形尺寸 | 方向 | 沿轨迹移动后的效果 |
|---|---|---|
| 全屏（画布大小） | 矩形透明 inside | 挡板移开，**扫过处永久显现**子视频（累积擦除） |
| 小矩形（窗口大小） | 只露矩形 outside | 只有框内看得见子视频（**探照灯**） |
| 全屏 | 只露矩形 outside | 反向：从全显示逐渐消失 |
| 小矩形 | 矩形透明 inside | 反向：框内被挖掉、露出主视频 |

> 这套模型不需要「历史累积」机制：遮挡由挡板**当前位置**决定，移开即撤销，所以单调轨迹下视觉上就等价于累积。

### 2. 参数

- **边缘羽化**（像素，0 = 硬边）：建议 8~40，越大边缘越柔和，观感就是「慢慢显现」。实现是在 matte 生成后追加 `gblur=sigma=N`。
  - ⚠️ 做全屏挡板擦除时，请把矩形设得比画面**略大**（四边各多出约 2 倍羽化值），否则画面四边一开始就漏出半透明。
- **启用轨迹** + **编辑航点…**：复用画中画同款航点列表（`build_waypoint_expr`），给挡板指定移动路线。
  - ⚠️ 擦除效果要求轨迹方向**单调**（一直往同一边走）：中途折返时，挡板折回的地方会把子视频重新挡住。
  - 列表里的**「起始坐标… / 结尾坐标…」**打开可视化编辑器直接拖放挡板位置；采用 `free_layout`，挡板可以拖到画布外（擦除场景本来就需要起点或终点在画面外）。编辑器里改了挡板大小会换算回上面的「矩形坐标 宽/高」。
    > 实现注记：`_trajectory_dialog` 的 `edit_cb` 为 `None` 时这两个按钮**永久置灰**（与「启用列表轨迹」是否勾选无关）。遮罩接入时一度漏传，已补 `_mask_edit_cb`，并加静态审计 `tests/_test_traj_editcb_audit.py` 防回归。
- 坐标恒为**子视频最终渲染帧**（crop→rotate→scale 之后）的局部坐标，即「你实际看到的子视频」那块画面。想做整屏擦除，把子视频缩放到与主视频同尺寸即可（此时局部坐标 ≡ 画面坐标）。
- **航点画布 = 子视频最终渲染尺寸**（crop→rotate→scale 之后，由 `compute_final_size_with_order` 计算，与「尺寸唯一真源 = final_render_size」一致）：航点、挡板宽高、可视化画布三者**同一坐标系**，拖出来的坐标即最终坐标。窗口上会显示当前画布尺寸（如「画布 1920×1080」）；若显示「兜底」说明没探到子视频尺寸，请先选好子视频文件。
  - 该尺寸随航点一起存进工程（`mask_traj_canvas_w/h`）。滤镜生成时遮罩已排在 crop/rotate/scale 之后，`W`/`H` 正好等于这个画布尺寸 → 还原比例恒为 1，行程精确对得上；只有老工程或探不到尺寸时才用 1280×720 兜底。
    > ⚠️ **例外（2026-09-12）**：开了**画布模式**时遮罩段不再留在链尾，而是排在**画布合成之后**（见 §3 注记），坐标基准随之变为画布尺寸。

### 3. 滤镜链

不启用轨迹时仍是原来的双 `drawbox` 静态 matte，行为逐字不变（零回归）。启用轨迹后改为动态 matte：

> 遮罩滤镜在子视频链中的位置**已从「裁剪前（原始帧坐标）」移到「crop→rotate→scale 之后、format=rgba 之前」**（2026-09-10 修正）。原因：遮罩坐标空间必须与「最终渲染帧」一致，否则画布（最终尺寸）和滤镜（原始帧）对不上，拖出来的挡板位置会整体偏移。静止矩形的 `mask_x/y/w/h` 与轨迹航点现在都落在最终渲染帧上，与 `open_mask_dialog` 的画布同构。

> ⚠️ **画布模式例外（2026-09-12 修正）**：上面这条「遮罩恒在 crop/rotate/scale 之后」在**画布模式**下不成立。
> 画布模式会把内容贴到更大的画布上（`build_canvas_filtergraph`），而遮罩原先仍留在**前置链尾** →
> 遮罩作用在「内容还被裁成原始尺寸」的时刻，坐标却按**最终画布尺寸**回写 → 表现为「一开画布模式遮罩就失效 / 挡板位置整体漂移」。
>
> 修正做法：把原链尾遮罩区块抽成独立函数 `_build_mask_filter_block()`（可选 in/out 标签，都为 `None` 时与抽取前逐字节一致），
> 画布模式下由 `build_canvas_filtergraph` 把遮罩段**追加到画布 overlay 之后**：
> `… → {out}_pre`（画布合成结果）→ `_build_mask_filter_block` → `{out}`。于是遮罩坐标基准 = 画布尺寸，与编辑器所见一致。
>
> 判据收口在 `_canvas_defers_mask(settings)`（`canvas_mode and canvas_segments and mask_enabled`）；
> `build_video_filter_chain(..., include_mask=False)` 是「跳出链尾遮罩」的逃生阀。
> ⚠️ 这两处消费必须**始终一致**，否则会出现「双重遮罩」或「遮罩丢失」。
>
> 验证：`tests/_verify_canvas_mask_merge.py`（新旧模块同进程对拍，非画布 5 场景逐字符一致 = 零回归）
> + `tests/_verify_canvas_mask_ffmpeg.py`（真机 ffmpeg：矩形内 alpha=255、矩形外 alpha=0；旧版同点亮度 0 = 复现原 bug）。
> 已知边界：子视频画布若存在「第 2 段渲染缩放」，遮罩仍在缩放之前；坐标精确到该场景为止。

```
split=3[a][b][c];
[b]format=gray,drawbox=全屏涂底色[bg];
[c]crop='min(宽,iw)':'min(高,ih)':0:0,format=gray,drawbox=涂反向色[bx];
[bg][bx]overlay=x='(<轨迹x>*W/画布宽)':y='(<轨迹y>*H/画布高)'[,gblur=sigma=N][mk];
[a][mk]alphamerge
```

> 为什么不继续用 `drawbox` 定位？实测 `drawbox` 的 x/y 表达式里**没有时间变量**：`t` 是 thickness 选项的值，`T` / `n` 直接报 `Undefined constant`。动态 matte 必须改走 `overlay`（x/y 明确吃 `t`）。
>
> ⚠️ `overlay` 的 x/y 表达式里同样**没有 `iw` / `ih`**（实测 `Undefined constant or missing '('`），主输入尺寸要用 **`W` / `H`**（等价 `main_w` / `main_h`）。这里的主输入就是那张全尺寸灰底，所以 `W`/`H` 正好是子视频帧尺寸。

时间线换算与「简易位置」crop_pos、水印列表轨迹同款：取主视频 trim/变速设置（`motion_trim_start/motion_speed_factor`，无则 `_trim_speed_from_settings`），段时间=主视频原始时间 → 换算输出时间线。

## 十四、遮罩形状图（2026-09-10）

「遮罩 / 透明蒙版」窗口新增**形状图**：载入自制形状图（心形、星星等多边形，**格式不限**：png/jpg/jpeg/bmp/webp/gif/tif 均可，movie 滤镜全吃）代替矩形挡板做 matte。与矩形遮罩共用「矩形坐标」（形状边界框）、🎯 可视化选区、边缘羽化。**勾「启用轨迹」后形状沿轨迹移动**（心形探照灯/擦除，航点=形状左上角，与矩形挡板同款等比还原与时间换算）。

### 1. 两条 matte 路线（素材类型单选，载入时自动检测）

- **黑白亮度图**：`format=gray` 取亮度——白=显示、黑=透明。jpg/bmp 天然走这条。
- **透明底挡块**：`format=rgba,alphaextract` 按 **alpha 通道的不透明度**取形状——不透明处=形状、透明处=背景，**挡块颜色不限**（透明背景黑挡块是典型素材）。
- 自动检测：载入文件时 ffprobe 读 `pix_fmt`，带 alpha 通道（rgba/bgra/gbrap/ya8/yuva* 等，见 `_MASK_SHAPE_ALPHA_PIXFMTS`）→ 自动选「透明底挡块」；否则「黑白亮度图」。检测不准（如 8 位调色板 pal8 可能带 tRANS 也可能不带，保守归亮度路线）可手动改单选。
- **黑白反转**：素材黑白语义与预期相反时勾选（对形状路整体 `negate`）。

### 2. 滤镜链

```
format=rgba,split=2[a][m];
[m]format=gray,lutyuv=y=0|255[bg];                     ← outside=0(黑底) / inside=255(白底)
movie=<形状图>[pg];                                     ← 路径：\ / 转正斜杠、: 双重转义 \\:、
[pg]format=rgba,alphaextract|format=gray                  含 [ ] ' , ; 时同目录硬链接改名
    [,negate(反转)][,negate(inside)],scale=W:H,format=gray[shp];
[bg][shp]overlay=x=X:y=Y[,gblur=sigma=N],format=gray[msk];   ← 启用轨迹时 X/Y=轨迹表达式
[a][msk]alphamerge                                              同矩形挡板：'(<轨迹x>)*main_w/画布宽'
```

实现注记（都是实测踩过的坑，见 `tests/_verify_mask_png.py`）：
- **底色用 `lutyuv` 不用 `drawbox`**：movie 引入 rgb 源后格式协商会把 drawbox 拖进 `yuva420p`，drawbox 的 black 在 yuv 上=limited 16 → 形状图区域外整圈 alpha=16 漏光；lutyuv 是查表滤镜恒保持 gray，0 恒 0。
- **movie 单帧 EOF 后 overlay 默认 `eof_action=repeat`** 静止停留（t=2.5s 实测 alpha 不变），无需 `loop`。
- **冒号双重转义**：filtergraph 层与 movie 参数层各吃一次转义，`C:/x.png` 必须写成 `movie=C\:/x.png` 中的 `\:` → 实际构造用 `.replace(":", "\\\\:")`（Python 字面量 `\\:`）；单层转义会 `avformat_open_input 'C'` 截断。
- 路径安全化：`_mask_shape_movie_path`（模块级，`build_video_filter_chain` 拿不到 `self._movie_path_safe`）——反斜杠转正斜杠 + 冒号双重转义 + 特殊字符硬链接兜底，登记 `_PREVIEW_LINKS` 程序退出统一清理。
- 设置字段：`mask_png_enabled / mask_png_path / mask_png_invert / mask_png_type`（`type` 参与路线判断 → canonical 英文 `bw|alpha`，UI 铁律）。

## 十五、遮罩多形状列表（2026-09-11）

「遮罩 / 透明蒙版」窗口重做为 **delogo 式单弹窗**：上方是**形状列表**、下方是**选中形状的参数**，原先独立的「多形状列表…」弹窗已删除。一个子视频可以叠加任意多个形状（普通矩形或外部形状图），每个形状各有自己的坐标、方向、时段／轨迹与羽化。

```
┌ 遮罩 / 透明蒙版 ──────────────────────────────────┐
│ [✓] 启用遮罩（作用于当前子视频）                   │
│ ┌ 形状列表（可加多个；点「启用」列切换单项）─────┐ │
```

编辑走**本地副本**：打开／取消不动已存数据；首次打开若列表为空而旧单形状字段有值，会自动搬成 1 行；保存时把**行 0 镜像回旧单形状字段**（兼容旧存档／旧路径）。

### 1. 类型：自动判定，不用选

- 「外部形状图」一栏**留空** → 普通矩形（`color=` 纯色挡板）。
- 有路径 → 外部形状图（`movie=` 载图）。
- 列表的「类型」列只是显示，没有下拉框。

### 2. 方向：每行独立

列表每一行各自选「只露矩形（outside）」或「矩形透明（inside）」，可以混用。列表里的「方向」列同步显示。

### 3. 时段：多形状**并行**，互不砍断（重点，最易误解）

**每个形状的时段各自独立；时段重叠时两个形状同时生效（并行），后一个的时段不会把前一个砍短。**

示例（真实 ffmpeg 逐像素探针 `tests/_probe_mask_time_overlap.py`）——A = 左侧矩形 0~3s，B = 右侧矩形 2~4s：

| 采样时刻 | 左侧（A） | 右侧（B） | 说明 |
|---|---|---|---|
| t = 0.5s | 255（亮） | 0 | 只有 A |
| t = 2.5s | **255** | **255** | **A、B 同时可见** ← 并行，不是把 A 砍到 2s |
| t = 3.5s | 0 | 255 | 只有 B（A 已按时结束） |
| t = 4.5s | 0 | 0 | 都结束 |

重叠区域怎么合成 → 由**方向 + 列表顺序**决定（**后行盖前行**，用「上移／下移」调层序）：

- **全「只露矩形」**：可见区**并集**（几块都亮）。
- **全「矩形透明」**：孔洞**并集**（整幅可见，孔各挖各的）。
- **混用**：后行盖前行。例：A「只露」0~3s + B「矩形透明」2~4s，则 2~4s 期间 B 在 A 的可见区上**挖孔**（探针 t=2.5 孔位 alpha=0）。

> 单个形状**内部**（开了轨迹时）另有规则：航点列表里第一个「段末动作 ≠ 保持」的段即终止点，其后的航点全部失效（见 `build_waypoint_expr`）。这是该形状自己的事，不影响别的形状。

### 4. 时段 与 轨迹 互斥

- 勾「轨迹（沿轨迹移动）」后，该行的「时段」被忽略、两框自动置灰（可见性交给航点）。
- 本质上「时段」就是「轨迹」的退化特例：一个静止航点 + 段末消失。所以二者放相邻（都在底部）。

### 5. 外部形状图：坐标里的 **宽 / 高就是渲染尺寸**（会缩放图形）

- 对**矩形**：宽／高 = 矩形大小。
- 对**外部形状图**：载入的图会被 **缩放到 宽 × 高**（`scale=W:H`），图像左上角落在 (x, y)。
- 所以换一张分辨率不同的图，只要宽／高不变，**呈现大小就不变**；想保持原图比例，请按原图长宽比填宽／高（不会自动等比）。
- 探针坐实：载入 60×30 的图、宽／高填 40×20 → 实际占位正好 **40×20**（40 宽以外、20 高以外 alpha=0，原图 30 高会命中的位置也不命中）。
- 「素材类型」（黑白亮度图／透明底挡块，取形状用哪条通道）见第十四章；🎯 可视化选区、边缘羽化对形状图同样生效。

### 6. 实现注记（本轮修复）

- ⚠️ **外部形状图会让形状外区域漏 `alpha=16`（约 6% 浅影，整帧浮出一层子视频）**：只要滤镜图里出现 `movie=`（rgb 源），ffmpeg 的格式协商就会把尾部 `format=gray` 走成 limited-range 的 RGB→Y，黑变 16。修法：底色画完后加 **`extractplanes=g`**（G 平面逐字节拷贝，黑=0 精确），与老单形状 PNG 路径同款修法（2026-09-11 探针复现并修正）。
- 底层仍是**一条 matte**：`format=rgba,split=3` → 底 matte（按首个形状方向取基准色）+ 主 alpha + 形状源；各形状按列表顺序 `overlay` 到同一条 matte 上（后盖先）→ 一次 `format=gray` + `blend=all_mode=multiply` + `alphamerge`。滤镜段由 `_build_mask_multi_shape_filters` 生成，列表为空时回退到旧单形状逻辑（老工程不破）。

## 十六、多流同步参考（多轨波形对齐 → 截取时间导出，2026-09-13）

同一个内容有多个版本的文件（不同机位、不同录制起点、或者同一个音乐的不同跳舞视频需要同步后左右平铺……），想把它们各截出**完全相同的同一段**——手工逐个试时间点非常痛苦。**多流同步参考**就是干这个的：把各轨音频波形叠在同一条时间轴上对比对齐，一次算出每条轨的 `-ss/-to` 截取时间。

### 1. 窗口概况

- **入口**：封装页轨道列表选择多条视频轨道后**右键「多流同步参考」**（紧随「创建缩略图」）。收 2~6 条视频轨，每条轨一条波形上下分道、共享同一条时间轴（横轴 = 参考轨时间）。
- **默认只读**：窗口只显示与复制时间，**不主动改动任何轨道数据**——算出的时间可拿去截取页手动使用；若想直接落到各轨截取设置，用右下角的**「写回时间」**（会二次确认，见本文第 4 步）。
- **波形增益**：每轨自动归一化到看得见（96% 分位定基准，轨头标注「显示增益 ×N」）。长视频前后响度差大、个别段落看着还是一条线时，可在轨头「增益×」框手动填放大倍数（**回车生效**，留空恢复自动），或点顶部「重新生成波形」重新解码。增益只影响观感，不动数据。
- **每轨轨头按钮**：`播放` / `时间预览` / `同步光标` / `打起始(all)` / `打结尾(all)`。窗口底部有「按光标对齐」「取当前帧对比」「从截取读回」，右下有「复制时间」「写回时间」。
- **同步光标**（2026-09-14，每条轨「打起始(all)」左边）：把**其余轨道的光标**挪到这条轨当前光标处的同一时刻（与「打起始(all)」同一套「按偏移反算」算法），**只挪光标——不打点、不改偏移、不重算漂移**。用法：在这条轨点到事件上 → 点「同步光标」→ 各轨波形一起跳过去核对是否真是同一个瞬间；确认无误再按右边的「打起始(all)」真正落笔。负时刻一律钳到 0。
- **取当前帧对比**（「按光标对齐」右侧，2026-09-14）：把**每条轨当前光标处的那一帧**取出来，平铺成网格同屏对比——对齐对上了，各格应当是同一个瞬间；没对上一眼看出差在哪。取的是各轨**自己时间轴**上的光标处（与「按光标对齐」同口径），所以先用自动找点/逐轨点光标让各轨光标落到同一事件再取。画面按原始比例缩放（竖屏素材居中补黑边，不拉伸），整窗绝不超出屏幕；对比窗**不用关**，回去挪光标后点窗内「重新取帧」即可刷新。格下方标注「基准/比对N · 文件名 + 该轨时刻」。
- **复制时间**（「写回时间」左边，2026-09-14）：只复制**汇总表当前选中行**的 `-ss X -to Y`（不含轨道名），直接粘进 trim 窗口 / 命令行；没选中行时按「当前轨」那一行走，并在提示里说明。想连区间长度、差值、漂移一起要，就双击那一行。
- **写回时间**（右下角，2026-09-14）：把当前对齐好的「起始/结尾」**写回外部轨道的截取设置**（`trim_enabled` / `precise_trim` / `trim_start` / `trim_end`，视频轨与同源音频轨同 key），写前二次确认；写完主窗轨道列表与命令预览即时刷新。这是本窗唯一会改动轨道数据的动作（见第 4 步）。
- **从截取读回**（2026-09-14）：把各轨**已设的截取数值**（trim 起点/终点）反向读进「起始/结尾」两格，并按「基准轨起始 − 本轨起始」重算偏移——上次把时间复制出去填进各轨 trim 后，重开窗口点一下就能接着调。没开截取的轨会跳过并列出（只读，不改轨道数据）。
- **对齐状态存档**（2026-09-14）：顶部「保存对齐… / 载入对齐…」把偏移 / 光标 / 起始-结尾 / 参考轨存成 JSON（按**文件路径 + 组内序号**记录：换一次选中顺序也能对上，**同一文件在轨道里重复出现（比如几段都取自同一素材）时第 k 个对第 k 个、各自也能对上**；部分匹配只恢复对得上的那几条）。**关窗时自动存一份**到配置目录 `sync_ref_last.json`，下次打开**同一批轨道**自动恢复并在提示栏说明——不用再把时间复制出去临时存放了。
- **不置顶**（2026-09-14）：本窗刻意不用 transient，可以和主窗自由切换（复制结果到别处时不会被挡住）。需要常驻最前时勾顶部「总在最前」（默认关）。

### 2. 推荐操作流程

#### 第 1 步：找特征点，按光标对齐

1. 在**某一条波形**上点「播放」，找一个声音特征明显、且其他轨里也存在同一声音的片段（一声鼓点、一句台词、一下关门声都行），把红色光标停在特征点上。
2. 到别的波形轨上找到**同一个特征点**——可以反复播放来回确认，把光标也停在相同位置。
3. 每条轨都照此放好光标后，点窗口下方的**「按光标对齐」**：各轨波形按「参考轨光标 − 本轨光标」平移，波形成列即对齐成功。

> 嫌逐轨手点麻烦，可用**「自动找点」**（在「光标 −1 帧 / +1 帧」那一行）：以当前轨光标处的 0.3 秒音频为模板，自动在其余各轨做互相关定位，精度约 0.1 毫秒。
>
> **搜索范围 = 按钮右边的下拉，默认 ±45 秒**：先在小窗口里找，找到「足够像」的就停；不够像才逐级往外扩（`±5 → ±15 → ±45 → ±120`）。
> 已经粗对齐过、偏差很小 → 选 **5**，最快也最准；偏差几十秒、不知道差在哪 → 选 **45** 或 **120**（越慢，越要核对）。
>
> 命中后状态栏会写明**「在 ± 多少秒内命中、相似度多少」**——相似度低（<0.35）、或存在另一个同样像的候选区时，会单独标「匹配不唯一」让你核对。命中**只挪光标、不直接写锚点**：看好再按该轨轨头的「打起始(all) / 打结尾(all)」。
>
> ⚠️ **光标一定要落在有声音的地方**。落在静音上会直接报错、拒绝执行（报「当前轨光标处几乎是静音（电平 x/32768）」）——静音只能跟静音对上，算出来的结果必然是错的，不如不做。

#### 第 2 步：打起始点（all）

1. 找到**错位后左边最短**的那条轨（即起始时间最短的，下例中的轨 1）。对齐后所有轨指向同一段内容，谁的源时间最小就以谁为起点基准。
2. 直接用它开头（0 秒）当起始；如果开头有一段不要的内容（比如 6 秒片头），就点这条轨的**「时间预览」**，跳到开头之后的位置点**「设为起点」**——该轨光标即移到 6 秒。
3. 在这条轨的轨头点**「打起始(all)」**：以该轨光标为基准，按已对齐的偏移给**所有轨道**同步写入起始点。

#### 第 3 步：打结尾点（all）

1. 选定用来做**结尾参考**的那条轨（比如轨 2），点它的「时间预览」找到结束时间，点**「设为终点」**把光标移到结尾。
2. 在这条轨 2 的轨头点**「打结尾(all)」**：同样给所有轨道同步写入结尾点。

#### 第 4 步：写回时间

对齐、打点都确认无误后，点右下角的**「写回时间」**——它把每条轨的「起始/结尾」写进对应轨道的**截取设置**（`trim_enabled` / `precise_trim` / `trim_start` / `trim_end`），**视频轨与同源音频轨**（同一文件的音频轨）一起写；缺起始或结尾的轨自动跳过并在提示里列出。写前会弹一次确认（这是本窗唯一会改写封装页轨道数据的动作），写后主窗轨道列表与命令预览即时刷新。

> 只想手动核对、或把时间拿去别处用，就点**「复制时间」**：复制**汇总表当前选中行**的 `-ss X -to Y`（不含轨道名），可直接粘进 trim 窗口 / 命令行。
> 汇总表各列为：轨道名 / 截取时间 / 区间长度 / 起始差 / 结尾差 / 漂移（差值 = 本轨 − 基准，正 = 事件在本轨更晚；基准行恒为「—」）。三行区间长度一致、漂移 0.000，说明起始/结尾打得干净：

```
基准 · 123.mp4	-ss 93.815 -to 171.207	77.392	—	—	—
比对1 · 321.mp4	-ss 6.567 -to 83.959	77.392	-87.248	-87.248	+0.000
比对2 · 1234.mp4	-ss 181.141 -to 258.533	77.392	+87.326	+87.326	+0.000
```

#### 第 5 步：在截取页核对

1. 切到**封装页面**，双击对应轨道打开**截取片段**窗口——起止时间已是第 4 步写回的值，**「精准到帧」**也已一并勾上（帧级精确截取、自动转重编码）。
2. 若要手动处理，也可在该窗点**「导入时间」**，从剪贴板读入 `-ss 开始 -to 结束` 填好起止。
3. 直接开始转换即可，逐轨重复。

## 十七、循环/绿幕页子视频音频模式（默认/忽略/混音/替换，2026-09-18）

在子视频（画中画 / 水印）的「循环/绿幕控制」页面，「透明度 / 遮罩」这一行的右边，新增了一个 **「音频:」下拉框**。它控制的是**这一条子视频自己的声音**要怎么处理——每个子视频独立设置，互不影响。

### 1. 四种模式怎么选

| 模式 | 效果 | 什么时候用 |
|------|------|-----------|
| **默认** | 子视频的声音作为一条**独立音轨**保留下来（跟以前的行为完全一样）。 | 你只是想把子视频叠上去，声音也照常保留、单列一条轨。 |
| **忽略** | 丢掉子视频的声音，只留画面。 | 无声水印 / 无声角标，不想让子视频发出任何声音。 |
| **混音** | 子视频的声音**混进主视频声音里**，不再单独出一条轨。 | 你想让子视频的解说 / 音效自然地融进主声。 |
| **替换** | 在主视频声音的基础上，**子视频显示的那段时间内，主声被静音、让子声顶上来**；那段时间过去，主声恢复。 | 想在子视频出现时"盖住"主声、只听到子视频的声音（例如插播一段配音）。 |

**关键点——四种模式里只有两种是"声画同时进出"：**

- **混音 / 替换**：声音严格跟着这条子视频的**显示区间**走——区间内出声、区间外静音。
  区间就是同页「显示时段」的起始 ~ 结束（循环次数决定区间多长）。画面出现它就出声，画面消失它就静音。
- **默认**：这一档是**保持独立音轨**（和以前完全一样），声音**不跟着显示区间走、也不跟画面同步**：
  它从 0 秒开始、按子视频自身的循环一直铺到片子结束。所以如果显示时段的起始不是 0，
  会出现"画面还没出现、声音已经响了"的错位；画面早消失了，声音也还在放。
  **要"声画同时进出"，请选 混音 或 替换。**
- **忽略**：压根没有声音，谈不上区间。

### 2. 跟背景音乐（BGM）怎么配合

如果你在主视频上还开了「背景音乐 (BGM)」：

- **替换**：显示区间内主声被静音，但 **BGM 依旧垫底播放**——那段时间你听到的是"子视频的声音 + BGM"，而不是一片死寂。（BGM 没开时，区间内就只有子视频的声音。）
- **混音**：BGM 和混完的主声+子声一起叠加输出，最终仍是一条音轨。
- **默认 / 忽略**：BGM 照旧垫在主声之下；默认模式下那条子视频的独立音轨是**额外一条**，不会被并进 BGM 那条。

### 3. 几个会自动处理的情况

- **子视频本身没有音轨**：混音 / 替换 会自动退化成"忽略"——不会出错，也不会把主声静音掉。
- **多个子视频同时用混音 / 替换**：各自按自己的显示区间生效，重叠的部分自然叠加，不会互相"吃掉"。
  一个用混音、另一个用替换也一样：替换那段主声静音，混音那条照常叠上去。
- **主视频自己没有声音**：混音 / 替换 会用静音垫底，输出里只剩子声（有 BGM 就再加 BGM），不会报错。
- **采样率 / 声道不一致**：工具会自动把参与混合的音频统一到同一规格，避免爆音或声道错位。

### 4. 会得到几条音轨

| 这条子视频选的模式 | 输出音轨的变化 |
|---|---|
| **混音 / 替换** | 并进主声那一条（BGM 也在这一条里）—— **不多出音轨** |
| **默认** | **多出 1 条**独立音轨（每条这样的子视频各算一条） |
| **忽略** | **不多出** |

### 5. 一句话总结

**「音频」下拉就是给这条子视频选：它出现的时候，声音是 从此静音（忽略）、单独出一条轨（默认）、融进主声里（混音），还是把主声顶掉（替换）。** 混音 / 替换 的区间跟画面走，不用额外设置。

## 十八、画中画转场（片段间交叉过渡）与音频对齐（2026-09-25）

> 这一章专门讲今天新加的三块：**转场（交叉过渡）**、**转场对齐**、**音频跟随转场**。
> 把"什么情况下才生效"列得最细，因为**它们都不是自动生效的，必须满足一串前置条件**——少一个就静默不生效（命令行看起来没变），容易以为功能坏了。

### 0. 先立个模型：这就是一条「真时间轴」

看懂这一章一切规则的前提，是先摆正心智模型。**画中画的这套能力，本体就是一条真时间轴（Shotcut 那种）**，不是"小窗悬浮在主视频上"的老画中画：

- **所有段摆在同一条共享时间轴上**，每段用自己的「显示 起始 / 结束」（或有限循环次数换算出的窗口）决定"占时间轴哪一段"——这就是这段素材的入点/出点。
- **主视频是第一段**：时间轴从它算起；后面的素材摆到它之外时，工具自动用黑帧把底接长（时间轴跟着延到最晚的段结束）。
- **画面按窗口接力**：上一段结束 ≈ 下一段开始，画面就自然"切过去"；窗口重叠就两段同屏（小窗/铺满随你摆）——重叠共存也是真时间轴的合法状态，不是错误。
- **转场不是本体的组成部分，只是补在衔接处的一个可选效果**：衔接得上（首尾相接 + 两段长度都探得到），才在切过去的那一下加个淡入/擦除等过渡；衔接不上就退回硬切。转场有那么多前置条件，根源就在这——工具要先能"排出时间轴"（每段多长、从哪到哪），才谈得上在衔接点装效果。
- 三块功能各管模型的一件事：**转场** = 衔接处的效果；**转场对齐** = 把入点精确摆到衔接点（起点数字 = 真实切换时刻）；**音频跟随转场** = 让这段声音跟着衔接点走（声画同切）。

> 实现说明（不影响用法）：底下的实现手段是 overlay 叠加 + 主视频尾部补黑帧，**不是 concat 拼接滤镜**——所以它比串行合并表达力强（段可重叠、可小窗、位置随段保留）；「串行合并」模式才是真拼接，两者别混。记**「真时间轴」**这个名字就够了。

一句话：**先当真时间轴用（排段、衔接），再想要过渡时才开转场**。后面的触发条件、对齐公式、音频跟随，全是这个模型的细节。

### 1. 三块分别是什么、在哪能看见

| 功能 | 是什么 | 入口（只画中画模式有，串行模式另算） |
|------|--------|----------------------------------------|
| **转场（交叉过渡）** | 上一段画面和下一段画面之间做淡入淡出 / 擦除 / 滑动等过渡，而不是"硬切" | 每段视频轨「淡入淡出」页的「启用转场」勾选框（末段灰显） |
| **转场对齐** | 一个按钮，把某段"开始显示的时间"自动算到"画面真正切到这一段的那个瞬间" | 仅**子视频**（非主视频）「淡入淡出」页，主视频页还有「一键转场(all)」会顺带对所有段对齐 |
| **音频跟随转场** | 一个勾选框，让这段声音跟着转场走、声画逐帧对齐，且只出一条音轨 | 仅**子视频**（非主视频）「淡入淡出」页，**默认不勾选** |

> 注意：这三个都**只在画中画模式**出现/生效；串行合并模式有自己的转场（第八·2 节，机制类似但拼接规则不同），不受本章"对齐/跟随"影响。

---

### 2. ⚠️ 转场真正生效（成链）的触发条件 —— 四条全满足

转场不是勾了就出效果，必须满足下面**全部**条件，否则工具会悄悄跳过（命令行里没有过渡、看起来像没反应）：

1. **必须是画中画模式**（废话但先说清楚）。
2. **上一段必须勾了「转场」**——转场是挂"上一段"身上的，控制的是"上一段 → 本段"之间的过渡。
   - 例：想让 段1→段2 过渡，要在**段1**的转场框勾上（段2 勾的转场控制的是"段2→段3"）。
   - 主视频勾转场 → 主视频作为链首，和"显示起点 ≈ 主视频时长"的那个子视频过渡。
3. **两段在画面上要"首尾相接"**：上一段的"结束显示时刻" ≈ 本段的"开始显示时刻"（差不超过半帧）。
   - 中间有空隙、或两段重叠 → 不成链，两段各显示各的、互不影响（硬切）。
4. **上一段和本段都得有"有限显示时长"**。满足下面**任意一种**即可：
   - ① 在「循环/绿幕控制」页填了**「显示 结束」**时间（起始+结束都填，窗口就有界）；
   - ② 或勾了**「启用循环控制」并设了有限的循环次数**（不是"无限循环"）。
   - 如果一段"没填结束 + 无限循环"，工具探不到它多长 → 不成链 → 转场静默不生效。

另外自动规则：
- 转场时长会被自动压到"相邻两段里较短那段的时长的一半"（避免太短出错）。
- 转场会"吞掉"转场时长：后一段比你在界面上摆的位置**提前**那么多秒出现（画面提前切过去了）。这就是"转场对齐"要解决的问题（见第 3 点）。
- **位置/轨迹/旋转在过渡中完整保留**：每个参与过渡的子视频，先把画面（含你设的叠加位置、轨迹移动、旋转偏移、缩放）烙进一张和主视频一样大的"透明画布"再过渡——
  - 你把两个子视频都摆在右下角 → 过渡就在右下角做，小窗外的透明处透出主视频；
  - 尺寸也不拉伸：子视频保持你设的大小，多余的地方是透明的；
  - 主视频勾了转场（主视频也进链）时同样成立：主画面过渡到"右下角小窗的子视频"，位置不丢；
  - 例外：**混合模式（blend）的子视频不参与过渡**（它需要和主视频像素混着算，过渡链是独立画面做不到）；其余（旋转/轨迹/子画布）都能进链。

> **一句话**：想让 段A→段B 有转场，就给段A 勾转场 + 让段A、段B 首尾相接 + 两段都给个"有限显示窗口"。

---

### 3. 转场对齐 —— 怎么用、何时生效

- **它是手动按钮，不会自动跑**。命令生成端不调用它，只有你点按钮才生效；"什么都不点" = 和以前完全一样，不影响任何存量项目。
- **公式（一眼看懂）**：
  ```
  本段开始 = 上一段开始 + 上一段长度 − 上一段转场时长
  ```
  - 例：主视频 12 秒、转场 2 秒 → 第一段子视频开始 = 12 − 2 = **10 秒**（画面在 10 秒就切过去了，不是 12 秒）。
  - 再下一段：以上一段算出来的"新开始"为基准继续累计。
- **参考哪一段**：一律取"轨道列表里紧挨着的前一段"（按你添加文件的顺序），**不按界面上摆的时间排序**。否则你把某段摆到后面时，会把它后面那段错当成"前一段"（之前踩过的坑：第 2 个对齐却用了第 3 个的时间）。
- **前置**：上一段要有可探到的显示长度（填起始+结束，或有限循环次数）。探不到会弹提示让你先设。
- **连"结束"一起平移、段长不变**：只改开始会把这段拉长，所以结束也跟着挪同样多。
- **一键转场(all)**：在主视频「淡入淡出」页点，会一次性给所有段开转场，并顺带做完对齐（不弹窗，只写日志）。

---

### 4. 音频跟随转场 —— 怎么用、何时生效

- 子视频「淡入淡出」页的勾选框，**默认不勾选**。
- **勾上之后会自动把「循环/绿幕控制」页里那个"音频:"下拉切到"混音"**——所以你不用再手动去勾混音；勾了就自动并成一条音轨输出（与串行模式的音频跟随口径一致）。
- 它让这段声音**直接落在"画面真正切到这段的那一刻"**（过渡的交叉点），声画逐帧对齐，不会"画面早切了、声音还停在原位"。
- **前置（视频侧，必须全满足，否则这个勾选框无效）**：
  1. 上一段转场已开 + 本段与之首尾相接（即第 2 点说的"成链"）；
  2. 本段有有限显示窗口（同第 2 点条件 4：显示结束 或 有限循环次数）。
  - 不成链时勾了也无效，音频留在"原显示位置"（和没勾一样）。
- **音频截取不用你手动做**：它自动按本段"显示窗口"（起始+结束 或 有限循环次数）裁切并定位；你调显示窗口就是调音频窗口。
  - 想要"音视频分离、音频单独偏移"那种自由度（像 Shotcut 那样）是另一项功能，暂未做；当前音频与显示窗口绑定。

### 5. 和升级前（画中画还没有转场能力时）的区别（重点）

> 这里的"升级前"指**画中画完全没有转场功能的版本**——那时段与段之间只能硬切，没有过渡、没有对齐、没有音频跟随。不是拿某个中间版本比。

| 场景 | 升级前（没有画中画转场的版本） | 升级后（现在） |
|------|--------|--------|
| 段与段之间怎么切换 | 只有**硬切**：上一段画面结束，下一帧直接换下一段，没有任何过渡效果 | 多了「转场」勾选框（挂在上一段上），勾了之后两段之间做淡入等**过渡**（前置：两段首尾相接 + 都有有限显示窗口） |
| 起点怎么摆 | 没有转场，不存在"差一个转场时长"的问题，起点摆哪就从哪开始 | 有了转场后起点容易摆错位 → 多了「转场对齐」按钮 + 一键转场顺带对齐，起点数字 = 真实切换时刻 |
| 子视频音频 | 已有「音频：」下拉（默认/忽略/混音/替换），要**自己手动选**混音才能并入主声 | 下拉还在、默认行为**不变**；另加「音频跟随转场」：勾上**自动**把音频切到混音 + 自动对到过渡交叉点，不用再手动去选混音 |
| 开了转场后的声音 | 不适用（那时没有转场） | 开了转场但**没勾**「音频跟随转场」时，声音还在原显示位置，会和过渡的画面错开；勾了才逐帧对齐 |
| 子视频的位置/轨迹/旋转 | 一直生效（本来就没有过渡会碰它） | 依然**全部生效**（过渡段先把画面烙进统一画布再过渡，位置随段保留）；唯一例外：混合模式（blend）的子视频不参与过渡 |
| 什么都不设置 | 自动循环 + 按主视频时长结束 | **完全相同**（新功能全靠手动点/勾触发，默认不改变存量行为） |

> 关键点：**新能力全部是"点按钮 / 勾框才生效"，默认保持旧行为**。你照旧用自动循环 + 主视频时长结束，完全没问题；只有主动用了转场/对齐/跟随后，输出才会变。

#### 再往前：真时间轴模型本身带来什么（模型之前 → 之后）

上面那张表对比的是"转场功能有没有"；这里再往前追一层——对比**真时间轴模型建立之前**的老画中画（主视频当底、输出时长恒等于主视频时长）。那时把子视频的开始摆到主视频之外，工具**不会自动算新时长、也不会自动补相关参数**，具体差在这几处：

| 想做的事 | 模型之前（老画中画） | 模型之后（现在） |
|------|--------|--------|
| 把子视频开始摆到主视频时长之外 | **输出时长不会自动延长**：总时长仍按主视频算；而且 overlay 叠加的"主输入结束 = 整条输出结束"，`-t` 给再大也拿不到帧 → 子素材**整段消失**，且无任何提示 | 自动扫所有段的窗口结束取最大值 → 主视频尾部**自动补黑帧**（`tpad=stop_mode=add`，精确零误差），总时长用新值，子素材完整出现 |
| 想让两段之间做过渡 | 画中画没有转场；就算手动往命令里拼 `xfade`，两段**尺寸 / 帧率 / SAR 不同会直接报错**（`size ... do not match` / `timebase ... do not match`），得自己补 `scale`+`setsar`+`fps` 三件套归一，还要手算 `offset`、把转场时长钳到较短段的一半以内，漏一步就报错或退化 | 勾个转场就行：参与过渡的段**自动补归一**（画布统一后连尺寸拉伸都省了），`offset` 自动算、转场时长自动钳制，不转场的段零归一 |
| 被截段 / 无限窗口的提示 | **完全静默**：窗口无限的段探不到长度，被整段截掉、也没法和相邻段成链，日志一个字不提 | 日志点名提醒：某段起点在输出时长之外但窗口无限时，提示「是否有素材忘了开有限时长？」（见第 7 点 Q&A 第一条） |

> 一句话：模型之前"摆到主视频外面 = 白摆"，要过渡得手动拼滤镜、参数全自己补；模型之后时间轴自动延长、转场参数自动补齐——你要做的只剩"给每段一个有限窗口 + 勾转场"。

### 6. 推荐操作顺序（避免踩坑）

1. 开画中画模式，加主视频 + 子视频。
2. 每段：在「循环/绿幕控制」页给个**有限显示窗口**（填「显示 结束」，或勾「启用循环控制」设有限次数）。
   → 改完不确定时间轴上有没有空隙 / 重叠，可打开【二十、「时间分配总览」】窗口一眼看全（右键菜单 →「时间分配总览」）。
3. 逐段勾「转场」（主视频 → 子1 → 子2 …），类型/时长自定。
4. 子视频「淡入淡出」页：先点「转场对齐」（按上一段算起点），再勾「音频跟随转场」（自动混音 + 定位）。
   - 或偷懒：直接在主视频页点「一键转场(all)」一次性全开+对齐，再逐子视频勾「音频跟随转场」。
5. 预览 / 导出。

### 7. 常见问题（为什么我点了没反应）

- **Q：勾了转场但命令没变化？**
  → 多半是：窗口无限（没填结束 + 无限循环）、或上一段没勾转场、或两段没首尾相接。回头看第 2 点四条，逐条核对。
  → 2026-09-25 起日志会点名提醒：某段的起点在输出时长之外但窗口无限时，会提示「是否有素材忘了开有限时长？」——看到这条就是第 4 条（有限显示窗口）没满足。
- **Q：勾了音频跟随还是多条音轨 / 声音还是错位？**
  → 得先"成链"（上一段转场 + 首尾相接）勾跟随才有效；不成链时它无效，音频留在原显示位置（和没勾一样）。勾上时应看到「循环/绿幕控制」页的"音频:"自动变成"混音"，没变说明没成链。
- **Q：声音还是比画面早/晚？**
  → 说明没成链，音频在原始显示位置。先确认命令里出现了过渡（成链成功），再勾跟随。
- **Q：第 2 段对齐用了第 3 段的时间 / 第 3 段把自己当第 2 段？**
  → 这是修过的旧坑：对齐一律按"轨道列表顺序的紧邻前一段"取，不再按界面摆的时间排序。若仍异常，确认没把段顺序拖乱。
- **Q：我给子视频设了叠加位置 / 轨迹 / 旋转，开了转场后这些都没了？**
  → 2026-09-25 起不会了（画布统一方案）：每个参与过渡的子视频都先把画面（含位置/轨迹/旋转）烙进统一透明画布再过渡，位置随段保留、尺寸不拉伸、透明处透出主视频。若发现位置仍丢，确认没给该子视频开混合模式（blend 不参与过渡）。

## 十九、节点：视频节点 / 音频节点（2026-09-25 / 2026-09-26）

> 这章讲两个入口：**视频节点**、**音频节点**，都在右键菜单里。
> 用途一句话：**把处理链中间某个位置当成一条独立素材来对待，给它单独套一组效果。**

### 1. 先理解"节点"是什么

一条画中画/串行合并的命令，内部是一条处理链，链上有若干中间输出（比如 `[1:v]` 经过缩放裁剪后又生成的新分支）。**"节点"就是这些中间输出的那个位置。**

- 选中一个节点 → 对它**之后**的所有画面 / 音频套一组效果；它前面的部分不受影响。
- 效果记在 `节点` 里（按"位置指纹"记），**之后每次重新生成命令都会自动插回这个节点之后** —— 不用手动改命令、也不用跑两次中间文件。

### 2. 两个入口与可用范围

| 入口 | 可用模式 | 打开的编辑窗 |
|------|---------|-------------|
| 「视频节点」 | **仅画中画**（非画中画置灰） | 「视频轨道设置」（把它当一条视频轨道来配：裁剪 / 旋转 / 轨迹 / 区域效果一族……） |
| 「音频节点」 | **画中画 + 串行合并**（普通封装置灰） | 「音频轨道设置」（音量 / 响度归一化 / 声道……） |

两者**互不交叉**：视频节点只列处理链里的视频段，音频节点只列音频段。

### 3. 视频节点：怎么选、怎么配

1. **右键** →「视频节点」→ 先自动刷新一次命令预览，把当前处理链取出来。
2. 弹出「视频节点」窗口：左边一棵两级树（一级 = 处理阶段：主链 / 子链 / 叠加 / 转场 / 收尾，二级 = 节点），每行显示序号、末滤镜、尺寸、**已挂效果**。
3. 选中某个节点 → 右边**窗内**立刻显示这个节点在"取帧时间"的真实画面与真实尺寸（含它前面已经挂上的效果）。取帧走内存管道，**不落盘**，取帧期间列表照样能点。
4. 确认后打开「视频轨道设置」，像配一条普通视频轨那样配参数。
5. 保存 → 提示"已记录 N 个节点效果"，命令预览同步刷新。

**典型场景（去水印）**：

1. **问题**：水印占据整个边角，直接用 delogo 会因为 2 个边角没有合适的参考像素，应用滤镜后还是很突兀。
2. **叠一层补参考像素**：给这个视频叠一层 —— **把适合的背景裁剪后拉到那个边角**，给那 2 个边角补点参考像素；也可以直接用一张提前处理好的 png 叠加一层。
3. **这个时候主视频和这个叠加层还是分离的**（叠加层是单独的一路，没有改掉主视频原本那一块画面）。
4. **以前本程序只能分两次做**：先转换输出一次，把输出的文件重新载入，再对它使用 delogo。
5. **现在**：直接在**合适的节点**上再应用一次 delogo —— **一次输出**，画面损失小。

### 4. 音频节点：怎么用

流程同视频节点，只是选的是音频中间节点，打开的是「音频轨道设置」。
常见用法：**在末节点统一补一个响度**（`loudnorm` 之类），一次输出把所有片段拉到同一响度。中间的音频节点可用的滤镜本来就少，聊胜于无。

### 5. 定位机制与失效重选（重要）

- 节点**不是按标签名定位的**，是按「**段序号 + 末滤镜名**」这个指纹定位的。
- 好处：PiP 级联时 `amix` 每段输出可能都叫同一个名字，靠名字会认错；按指纹能精确命中。
- 代价：**处理链结构变了**（增删或开关了某个处理环节）就可能找不到这个位置 → 工具会**跳过并提示**，不会悄悄改错；这时回到「视频节点 / 音频节点」重新选一次节点即可。
- 同名标签显示时会追加「同名 n/m」便于区分；点选后下方会显示"原始标签：[真实名字]"。

### 6. 已知限制

- **分叉段不给插**：只有"单输出标签"的节点会出现在列表里（一个节点分出好几路的语义不明，本轮不给插）。
- 节点效果只在**画中画 / 串行合并**这两条链里生效；普通封装模式没有中间节点可用。
- 一个节点上可以挂多个效果，列表里的「已挂效果」列会显示摘要。

## 二十、时间分配总览（画中画专用，2026-09-27）

> 这一章是【十八】章那条「真时间轴」的**直观版**：一条时间轴看完全部片段，可以拖着改。
> 细节不在这里重复——各按钮 / 各手势在封装页「循环/绿幕控制」「淡入淡出」「子视频控制」页里都有同名的同款控件，
> 鼠标停在上面有完整说明。**这一章只列"和别处有什么不一样"。**

**它是什么**：画中画每条视频轨都有「显示时段（开始显示 / 结束显示）」，平时一条条改容易漏；
这个窗口把全部片段画在同一条时间轴上直接拖，改完自动重画。

- **只读写各视频轨的"显示时段"**，与命令端 `_resolve_display_window` / `_pip_timeline_extent` 同源 —— 看到的就是命令跑出来的。
- 打开条件：画中画模式 + 至少 2 个视频轨；入口是右键菜单 →「时间分配总览」。
- 和位置编辑器是两回事：**这里拖的是"时间"**，小窗摆在哪不在这里改。

**和别处不同的四点**：

| 别处 | 这里多给的东西 |
|------|---------------|
| 只能一条条改数值 | 拖条粗调 + 自动吸附（吸到别的素材端点 / 主视频首尾 / 时间轴末端 / 手动 `-t`；拖时按住 **Shift** = 强制吸附） |
