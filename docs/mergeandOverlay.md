# 合并/封装/画中画页面功能总结

## 一、页面概述

合并页面（封装/合并/画中画）是 FFmpeg 多功能工具的核心模块之一，用于将多个视频、音频、字幕流组合成一个输出文件。它支持三种主要工作模式：

- **普通封装模式**：将主视频与外部音频/字幕合并，可重新编码或流复制。
- **画中画模式**：将一个或多个子视频（或图片）叠加在主视频之上，支持位置、大小、透明度、绿幕抠像、循环播放等高级效果。
- **串行合并模式**：将多个视频按顺序首尾拼接，支持流复制（快速）或重新编码（兼容性强）。

---

## 二、主要功能区

### 1. 主视频与轨道管理

- **主视频文件**：选择作为基底的主视频文件。
- **轨道列表（Treeview）**：
  - 显示所有已添加的轨道（视频、音频、字幕），包括启用状态、类型、规格（分辨率/时长/编码等）、编码设置等。
  - 支持双击编辑单个轨道的详细参数。
  - 支持拖拽添加文件（自动识别类型）。
  - 右键/工具栏操作：启用/禁用、编辑、预览、上移/下移、删除、清空、排序（按文件名或修改时间）、保存/加载项目。

### 2. 添加外部轨道

- **添加外部音轨**：导入音频文件（mp3, aac, wav, flac, opus, ac3 等）。
- **添加外部字幕**：导入字幕文件（srt, ass, ssa, vtt, idx, sup 等）。
- **添加外部视频**：在画中画或串行模式下，添加视频作为子视频或串联片段。

### 3. 模式选择与参数控制

#### 启用画中画 (PIP)
- 所有视频流强制重新编码（无法使用 copy），输出时长默认由主视频控制。
- 每个子视频可独立设置位置、大小、透明度、绿幕抠像、循环播放等。

#### 串行合并（首尾拼接）

这是将多个视频按顺序拼接成一个长视频的模式。它分为两种子模式，**但无论哪种，子轨道（非主视频）的独立滤镜（裁剪、缩放、旋转、增强等）和独立截取都会被完全忽略**，最终拼接结果只应用**主视频的全局滤镜设置**，作为模板。

- **流复制模式（Copy 模式）**：
  - **触发条件**：主视频和音频的编码器均为 `copy`，且所有输入视频的编码参数（分辨率、帧率、像素格式、编码格式）**完全一致**。
  - **实现方式**：使用 FFmpeg 的 `concat demuxer`（`-f concat -safe 0 -i filelist.txt`），直接在二进制级别拼接文件。
  - **特点**：速度极快（几乎等于文件复制），不重新编码，因此**所有滤镜（包括主视频的）都不会生效**，只做简单的首尾连接。
  - **限制**：要求所有视频参数严格一致，否则会导致花屏、音画不同步或播放异常。**子轨道自身的任何设置（滤镜、截取等）完全被忽略**。

- **重新编码模式（非 Copy 模式）**：
  - **触发条件**：主视频或音频的编码器不是 `copy`（例如设为 `libx264`）。
  - **实现方式**：使用 `filter_complex` 中的 `concat` 滤镜，先将每个片段仅做 `setpts=PTS-STARTPTS` 重置时间戳，再拼接成单一视频流，最后将**主视频的全局滤镜链**应用到拼接结果上。
  - **特点**：会重新编码所有视频，强制统一输出参数（分辨率、帧率、像素格式等），兼容性强。**子轨道（非主视频）的独立滤镜、裁剪、缩放、旋转、增强、截取等全部被忽略**，只有主视频的滤镜（裁剪、缩放、旋转、反交错、降噪、锐化、色彩校正、变速、倒放、像素格式、帧率、字幕烧录等）会作用于最终的拼接结果。
  - **典型用途**：将多个分辨率或帧率不同的视频拼接成统一规格的输出，或统一添加全局效果（如降噪、水印、调色等）。

> **重要提示**：由于串行合并会忽略子轨道的独立设置，如果您需要为每个片段单独裁剪、缩放或应用特效，请考虑使用 **“画中画”模式**（可独立调整每个视频）或 **“分段拼接”模式**（从同一源文件裁剪多个片段并拼接）。也可以在串行合并前，先将每个片段单独预处理（如裁剪、调色），再以处理后的文件进行串行合并。

#### 仅音频模式
- 输出纯音频文件，适用于多音轨混合（amix），此模式下视频轨道被忽略。

#### 手动时长
- 强制指定输出总时长（覆盖自动计算），用于防止因滤镜循环导致输出无限延长。

### 4. 章节与元数据处理

- **复制源文件章节**：自动保留主视频的章节标记（`-map_chapters 0`）。
- **导入外部章节文件**：支持 FFmetadata 格式的章节文件。

### 5. 输出设置

- **输出容器**：MKV、MP4、WebM（根据模式自动推荐）。
- **输出文件路径**：自定义保存位置。
- **合并成功后删除源文件**：谨慎使用，有二次确认。
- **验证输出文件**：合并后检查文件完整性。

### 6. 命令预览与控制

- **实时命令预览**：显示即将执行的 FFmpeg 命令（可编辑、但不影响原始命令，只作为可复制的临时修改）。
- **刷新命令**：强制重新生成命令。
- **复制命令**：将命令复制到剪贴板。
- **开始合并**：执行合并操作，实时显示进度日志。

## 三、画中画模式下的主视频偏移页面（详细说明）

当启用画中画模式后，编辑主视频轨道时，会进入一个包含 **“叠加/偏移”** 标签页的设置窗口。该页面分为左右两栏：

- **左栏**：主视频的画布偏移设置（pad 滤镜）。
- **右栏**：针对所有子视频（非主视频）的批量操作工具和智能平铺功能。

### 左栏 – 主视频画布偏移

- **启用画布偏移**：勾选后，主视频将被放置在一个更大的黑色画布上。
- **画布宽度/高度**：手动设置画布尺寸。
- **偏移 X/Y**：主视频内容在画布内的偏移量（支持负数）。
- **获取尺寸**：自动从主视频文件读取分辨率并填入。
- **可视化编辑画布偏移**：打开图形化窗口，拖拽蓝色矩形调整主视频在画布中的位置，可直观调整偏移量。

### 右栏 – 子视频批量操作与智能平铺

此区域提供对 **所有子视频（即除主视频外的所有视频轨道）** 的快捷操作，极大提升多视频布局的效率。

#### 按钮详解

| 按钮 | 功能描述 |
|------|----------|
| **取消子视频缩放/裁剪** | 一键取消所有子视频的“启用缩放”和“启用裁剪”复选框，恢复子视频为原始尺寸。适用于希望以原始分辨率进行平铺或手动调整的场景。 |
| **统一高度** | 将所有视频轨道（包括主视频）的高度统一为指定的像素值，宽度按原比例自动缩放。此操作会启用每个视频的缩放并设为“高度优先”模式。 |
| **统一宽度** | 与“统一高度”类似，将所有视频轨道的宽度统一为指定值，高度按比例缩放。 |
| **修改子视频编码** | 将所有子视频的编码器统一设置为 libx264（H.264）。只用来消除“copy 被忽略”的日志提示，没有其他实际用途。 |
| **恢复为 copy** | 将所有子视频的编码器恢复为流复制（copy），适用于计划从画中画变更到串行合并模式或需要保留原始编码的情况。 |
| **计算平铺** | **核心功能**：根据所有视频（主视频+子视频）当前的 **实际渲染尺寸**（考虑已应用的缩放、裁剪、旋转等），自动计算最佳排列布局，并更新每个子视频的叠加位置以及主视频的画布大小。 |

#### “计算平铺”参数说明

- **每行/每列**：控制横向优先或纵向优先时的基本单位数量。
- **方向**：可选择“自动”、“横排优先”或“竖排优先”。
  - **自动**：根据视频总宽高比自动选择更接近 16:9 的方向。
  - **横排优先**：按行排列，适合宽屏显示器。
  - **竖排优先**：按列排列，适合竖屏或手机视频。

**工作原理**：
1. 获取主视频的当前渲染尺寸（从滤镜设置中实时计算）。
2. 获取每个子视频的当前渲染尺寸（同样考虑其自身的缩放/裁剪）。
3. 根据所选方向，将视频排列成网格，计算所需画布的总宽度和高度。
4. 自动更新主视频的画布尺寸（pad 滤镜）和每个子视频的 overlay 坐标，使视频整齐排列在画布中。
5. 所有更改实时反映在轨道列表和命令预览中。

> **提示**：若要获得最佳的平铺效果，建议先使用 **“取消子视频缩放/裁剪”** 恢复所有子视频的原始尺寸，或手动调整每个子视频的缩放/裁剪，然后再执行“计算平铺”，以免尺寸不一致导致布局错乱。

## 四、其他便捷功能

- **保存/加载项目**：将当前所有轨道、设置、布局保存为 `.fflgproject` 文件，便于后续继续编辑。本质是 JSON 文件，可用文本编辑器打开查看或修改。
- **排序功能**：按文件名或修改时间对轨道排序（仅在串行合并模式下可用）。
- **拖拽添加文件**：支持从文件管理器直接拖拽文件到轨道列表，自动识别类型并添加。
- **轨道编辑**：双击任意轨道可进入详细设置，支持视频滤镜、音频参数、字幕语言/标题等精细控制。但在串行合并模式下，子视频的滤镜设置不会生效。

## 五、典型工作流程建议

### 场景 1：普通封装（单视频+音轨/字幕）
1. 选择主视频。
2. 添加外部音轨/字幕（普通模式）。
3. 调整主视频的滤镜（如有需要）。
4. 设置输出路径，点击“开始合并”。

### 场景 2：画中画（多视频叠加）
1. 启用画中画模式。
2. 添加主视频和子视频。
3. 双击每个子视频，设置裁剪/缩放/绿幕/循环等独立参数。
4. 如需批量布局，使用“取消子视频缩放/裁剪”恢复原始尺寸，再执行“计算平铺”。
5. 预览效果，调整位置（可手动输入坐标或使用可视化编辑器）。
6. 输出合并。

### 场景 3：串行合并（首尾拼接）
1. 启用串行合并模式。
2. 添加所有要拼接的视频（顺序可通过上移/下移调整）。
3. 检查视频参数是否一致（规格列显示分辨率/编码等信息）。
4. 若参数一致，保持所有编码器为 `copy`，使用流复制模式（最快）。
5. 若参数不一致，将主视频编码器设为非 `copy`（如 `libx264`），系统将自动采用重新编码模式，此时**所有子视频的独立滤镜设置会被忽略**，只有主视频的全局滤镜（如缩放、裁剪、调色等）作为模板，会应用到最终拼接结果。
6. 如需对每个片段单独处理（如裁剪不同区域），请先使用 FFmpeg 或其他工具预处理每个文件，再导入串行合并。
7. 设置输出，开始合并。

合并页面通过丰富的轨道操作、智能平铺、可视化编辑等功能，使得多视频合成、画中画制作、多音轨混音等任务变得高效且直观，是 FFmpeg 多功能工具中功能最强大、交互最丰富的模块之一。
